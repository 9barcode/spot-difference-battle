# UI 시안 점검

## 점검 대상

- `UI/src/app/App.tsx`의 Figma 기반 단일 페이지 시안
- `SCREEN_SPEC.md`와 `GAME_RULES.md`의 MVP 기준

## 결론

현재 시안은 시각 방향과 핵심 화면의 출발점으로는 사용할 수 있지만 제품 범위와 규칙을 그대로 구현 기준으로 삼을 수 없다. MVP에서는 핵심 대전 흐름을 남기고 메타게임 화면을 숨긴 뒤, 누락된 실시간 상태를 추가해야 한다.

## 유지할 화면과 요소

- 로비의 빠른 대전 진입
- 매칭 검색 및 상대 발견 상태
- 차이점 제작 화면의 타이머와 도구 영역
- 풀이 화면의 원본·수정 이미지 비교 구조
- 결과 화면의 승패와 경기 상세
- 진행도 점, 타이머 위험 상태, 정답·오답 피드백

## 수정이 필요한 항목

| 현재 시안 | MVP 기준 | 조치 |
|---|---|---|
| 차이점 5개 | 차이점 3개 | 모든 제작·풀이·결과 수치를 3개로 통일 |
| 로그인된 고정 프로필 | 게스트 닉네임 | 최초 진입과 닉네임 검증 상태 추가 |
| 코인·다이아·레벨 표시 | 수익화와 성장 제외 | 헤더에서 제거 |
| 랭킹·상점·시즌·퀘스트·업적 | MVP 제외 | 탐색 메뉴와 로비에서 숨김 |
| 데일리 도전·친구 대전 | 빠른 대전만 제공 | 보류 기능으로 이동 |
| 클라이언트 타이머로 화면 전환 | 서버 마감 시각과 상태 기준 | 서버 동기화 구조로 교체 |
| 하드코딩된 결과 | 실제 서버 경기 결과 | 결과 모델에 연결 |
| 데스크톱 고정형 사이드바 | 모바일 필수 | 작은 화면용 하단 또는 축약 탐색 설계 |

## 누락된 필수 화면과 상태

- 최초 접속 시 닉네임 입력과 오류 상태
- 제작 제출 확인 및 제출 후 상대 대기
- 제작 미완료 자동 보충 안내
- 문제 검증·교환과 풀이 시작 카운트다운
- 연결 끊김 및 10초 재접속 오버레이
- 서버 오류로 인한 경기 취소 결과
- 재대전 요청, 수락, 거절, 시간 초과
- 불공정 문제 신고 입력과 접수 완료
- 이미지 로딩 실패와 매칭 준비 실패

## 구현 전 UI 완료 조건

- 모든 핵심 화면에 기본, 로딩, 오류, 비활성 상태가 정의되어 있다.
- 차이점 수와 시간 수치가 게임 규칙과 일치한다.
- 모바일에서 제작 도구와 두 이미지를 사용할 수 있는 레이아웃이 있다.
- 네트워크가 느리거나 끊겨도 사용자가 경기 처리 방식을 이해할 수 있다.
- MVP 제외 기능으로 가는 활성 링크가 없다.
