# UI 현황 점검

> 문서 상태: CURRENT
> 기준일: 2026-08-31
> 책임 역할: UI·QA 책임자
> 화면 규칙은 `GAME_RULES.md`와 `SCREEN_SPEC.md`를 따른다.

## 현재 구현

활성 앱은 `UI/src/main.tsx`가 렌더하는 `MvpApp.tsx`다.

- 닉네임·로비, 모드·난이도 선택, 빠른 대전과 매칭 취소
- 양쪽 준비와 첫 문제·다음 문제 사전 로드
- 로드 실패 안내와 수동 재시도
- 문제를 가린 서버 기준 3초 카운트다운
- 양쪽 원본·변경본 비교와 변경본 선택
- 플레이어별 독립 발견·문제 이동
- 내·상대 현재 문제와 `찾은 수/실제 차이 수`
- 난이도별 오답 입력 잠금과 콤보 피드백
- 정답 점수·완주 시간 가산점과 첫 완주자 즉시 승리
- 승리·패배·무승부·취소 결과와 신고
- 재접속 안내와 서버 상태 복구
- 데스크톱·가로형 게임 WebView 좌우, 세로 모바일 상하 반응형 배치
- 원본·변경본 동기화 1~3배 확대와 드래그 이동

기존 객체 편집기와 제작 제출·힌트 코드는 활성 앱에서 제거됐으며 현재 앱은 동시 빨리찾기 흐름만 제공한다.

## 자동 검증

- 닉네임과 매칭의 키보드 조작·포커스
- 두 독립 브라우저의 준비·사전 로드·카운트다운
- 선택 난이도에 맞는 문제 풀
- 플레이어별 독립 진행과 첫 완주 즉시 결과
- 데스크톱·모바일 확대·드래그·정규화 좌표
- Chromium·Firefox·WebKit 프로젝트 구성

자동 테스트가 존재해도 최근 릴리스 후보에서 실행한 증거가 없으면 수동·운영 검증 완료로 간주하지 않는다.

## 남은 보완점

### P0 콘텐츠·출시

- 활성 16세트 전체의 실제 사용자·모바일 플레이 검수
- NORMAL·HARD에서 한 경기 무반복이 가능한 문제 수 확보
- 문제별 권리 증빙과 QA 승인 연결
- 공개 출시 모드·난이도 범위 결정
- 결과 화면에서 승패 근거가 되는 상대 오답 수 공개

### P1 UI·접근성

- 결과에서 모든 문제별 정답을 넘겨보는 화면
- 재접속 유예 10초의 실제 남은 시간 표시
- 스크린리더·색각·고대비·키보드 전체 흐름 검수
- 대표 iOS·Android·저사양 모바일·느린 네트워크 반복 검증
- 앱인토스 SDK 설정 후 샌드박스 앱에서 Safe Area와 844×390급 가로 화면 반복 검증
- 사용자 행동이 필요한 연결·서버 오류의 구체적 복구 안내

### P1 운영 경험

- 문제 신고 후 운영 검토 상태 안내
- 문제별 실패율·오답률을 확인하는 운영 화면
- 릴리스별 브라우저·기기 검수 기록

게임 수치는 공유 설정을 사용하며 서버 스냅샷으로 시간·점수·승패를 확정한다.
