# UI 현황 점검

> 문서 상태: CURRENT
> 기준일: 2026-08-04
> 화면 규칙은 `GAME_RULES.md`와 `SCREEN_SPEC.md`를 따른다.

## 현재 구현

활성 앱은 `UI/src/main.tsx`가 렌더하는 `MvpApp.tsx`다.

- 닉네임·로비·빠른 대전·매칭 취소
- 양쪽 준비와 첫 문제·다음 문제 사전 로드
- 문제를 가린 서버 기준 3초 카운트다운
- 양쪽 원본·변경본 비교와 변경본 선택
- 플레이어별 독립 발견·문제 이동
- 내·상대 완료 문제 수와 현재 발견 수
- 오답 1초 입력 잠금
- 승리·패배·무승부·취소 결과와 신고
- 재접속 유예 안내와 서버 상태 복구
- 데스크톱 좌우·모바일 상하 반응형 배치
- 원본·변경본 동기화 1~3배 확대와 드래그 이동

기존 객체 편집기 코드는 일부 파일에 남아 있지만 활성 `MvpApp`에서는 사용하지 않는다. 제작 제출·힌트 서버 이벤트도 호환 타입 외에는 경기 흐름에 사용하지 않는다.

## 자동 검증

- 키보드 닉네임·매칭 포커스
- 두 독립 브라우저의 준비·사전 로드·카운트다운
- 데스크톱·모바일 화면의 동일 문제 진입
- 준비된 문제 완료 후 경기 유지와 기권 종료 동기화
- Chromium·Firefox·WebKit 기본 흐름
- 데스크톱·모바일 확대·드래그·정규화 좌표

## 남은 보완점

### P0 콘텐츠

- 숲·바다 정답 영역의 실제 사용자 플레이 검수
- 최소 10개 문제 쌍 확보

### P1 UI·접근성

- 모바일 확대·이동과 선택 제스처 분리
- 문제 전환 애니메이션과 이미지 로드 실패 재시도
- 결과에서 모든 문제별 정답을 넘겨보는 화면
- 재접속 남은 시간 표시
- Firefox·WebKit 전체 브라우저 반복 검증
- 스크린리더·색각·저사양 모바일 점검

게임 수치는 공유 설정을 사용하며 서버 스냅샷으로 시간·점수·승패를 확정한다.
