# 사용자 흐름

## 1. 기본 흐름

`접속 → 닉네임 설정 → 로비 → 매칭 대기 → 상대 연결 → 차이점 제작 → 제출 대기 → 문제 교환 → 차이점 찾기 → 결과`

결과 화면에서는 다음 행동 중 하나를 선택한다.

- 같은 상대와 재대전
- 새로운 상대와 매칭
- 로비로 이동
- 상대 문제 신고

## 2. 화면별 흐름

### 접속 및 로비

1. 사용자가 게임에 접속한다.
2. 필요한 경우 닉네임을 입력한다.
3. 게임 방법과 현재 접속 상태를 확인한다.
4. `매칭 시작`을 선택한다.

### 매칭

1. 매칭 대기 화면으로 이동한다.
2. 상대가 연결되면 양쪽의 준비 상태를 확인한다.
3. 원본 이미지를 불러온 뒤 제작 단계로 이동한다.

사용자가 대기를 취소하면 로비로 돌아간다. 제한시간 안에 상대가 입장하지 않거나 이미지 준비가 실패하면 매칭을 취소하고 원인을 안내한다.

### 차이점 제작

1. 원본 그림과 남은 시간을 확인한다.
2. 제작 도구를 선택해 차이점을 추가한다.
3. 시스템의 유효성 검사를 통과한 차이점만 등록된다.
4. 차이점 3개를 완성하면 제출할 수 있다.
5. 제출 후 상대의 제출을 기다린다.

제작 시간이 끝났을 때 미완성된 항목은 시스템이 보충할 수 있다. 자동 보충을 제공하지 않는 빌드에서는 해당 경기를 취소하거나 미완성 플레이어의 패배로 처리하지 않고 별도 안내한다.

### 차이점 찾기

1. 원본과 상대가 수정한 그림을 확인한다.
2. 수정된 그림에서 차이가 있다고 생각하는 위치를 선택한다.
3. 정답이면 찾은 개수와 표시가 갱신된다.
4. 오답이면 남은 시간이 3초 줄어든다.
5. 필요하면 경기당 한 번 힌트를 사용한다.
6. 한 명이 모두 찾거나 시간이 끝나면 결과 화면으로 이동한다.

## 3. 예외 흐름

### 연결 끊김

- 일시적 끊김: 경기 화면을 유지하고 재연결 상태를 표시한다.
- 10초 안에 복귀: 서버 상태를 다시 받아 경기를 이어간다.
- 10초 안에 미복귀: 연결이 끊긴 플레이어의 기권패로 종료한다.

### 직접 이탈

경기 중 나가기를 선택하면 기권 처리됨을 확인한 뒤 종료한다. 매칭 대기 중 취소는 기권으로 보지 않는다.

### 서버 또는 이미지 오류

승패에 영향을 주는 서버 오류나 이미지 로드 실패가 발생하면 경기를 취소한다. 사용자가 다시 매칭하거나 로비로 돌아갈 수 있게 한다.

### 재대전

양쪽 모두 제한시간 안에 재대전에 동의하면 새 경기로 이동한다. 한쪽이 거절하거나 응답하지 않으면 상대에게 새 매칭과 로비 이동을 제공한다.

### 신고

결과 화면에서 신고 사유를 선택하고 제출한다. 신고 완료 여부만 알리고 즉시 제재 결과를 약속하지 않는다.
