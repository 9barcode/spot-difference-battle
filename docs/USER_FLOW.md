# 사용자 흐름

> 문서 상태: CURRENT
> 기준일: 2026-08-31
> 책임 역할: 제품·UX 책임자
> 규칙은 `GAME_RULES.md`를 따른다.

## 전체 흐름

`접속 → 닉네임 → 모드·난이도 선택 → 매칭 → 준비 → 문제 사전 로드 → 3초 카운트다운 → 반복 풀이 → 결과 → 로비`

## 매칭과 준비

1. 사용자가 닉네임을 저장하고 모드·난이도를 선택한다.
2. 빠른 대전을 누르면 서버가 같은 설정의 상대를 찾는다.
3. 매칭된 양쪽이 준비한다.
4. 서버가 선택 난이도에 맞는 동일 문제 순서와 버전을 확정한다.
5. 클라이언트가 첫 문제와 다음 문제 이미지를 미리 불러온다.
6. 양쪽의 같은 첫 문제 버전 로드 완료 후 문제를 가린 채 3초 카운트다운한다.

## 경기

1. 원본과 변경본을 비교한다.
2. 변경본에서 차이점을 선택한다.
3. 정답이면 자신의 발견 표시, 진행과 콤보가 갱신된다.
4. 이미 찾은 곳은 다시 눌러도 불이익이 없다.
5. 오답이면 오답 수가 증가하고 난이도에 따라 0.5~2초간 입력이 잠긴다. 생존전은 누적 3회 오답 시 패배한다.
6. 현재 문제에 등록된 차이를 모두 찾으면 완료 표시 후 즉시 다음 문제로 이동한다.
7. 한 플레이어가 전체 덱을 먼저 완주하거나 제한시간이 끝날 때까지 반복한다.

상대 화면에는 현재 문제와 `찾은 수/실제 차이 수`만 보이며 정확한 발견 위치, 오답과 입력 잠금은 보이지 않는다.

## 종료와 결과

- 첫 전체 완주: 서버가 즉시 해당 플레이어의 승리로 종료한다.
- 제한시간: 총점이 높은 플레이어, 다음으로 오답이 적은 플레이어가 승리하며 모두 같으면 무승부다.
- 생존전 오답 한도: 한도에 먼저 도달한 플레이어가 패배한다.
- 기권: 나간 플레이어의 상대가 승리한다.
- 취소: 서버가 결과를 신뢰할 수 없으면 승패 없이 종료한다.

결과에서 양쪽 점수 구성, 최종 진행과 종료 사유를 확인한다. 현재 행동은 로비 이동과 문제 신고다. 문제별 전체 정답 검토, 재대전과 즉시 새 매칭은 후속 기능이다.

## 후속 1인 연습

온라인과 같은 이미지 쌍과 정답 영역을 사용한다. 혼자 연속 문제를 풀며 이미지와 판정을 검증한다. 힌트나 시간 제한 해제는 연습 전용 선택 사항이고 온라인 전적·신고에는 연결하지 않는다. 구현 우선순위는 `REVIEW_REQUIRED.md`의 `REV-012`에서 결정한다.

## 예외 흐름

- 매칭 취소: 로비 복귀, 기권 아님
- 준비 30초 초과: 승패 없이 취소
- 사전 로드 15초 초과·실패: 재시도 또는 승패 없이 취소
- 직접 나가기: 상대 기권승
- 연결 끊김: 10초 복귀 유예 후 미복귀 시 상대 기권승
- 서버 판정·저장 신뢰 불가: 승패 없이 취소
- 문제 이미지·공정성 오류: 완료 또는 취소 화면에서 신고

화면 구현과 남은 예외 안내는 `SCREEN_SPEC.md`와 `UI_AUDIT.md`에서 추적한다.
