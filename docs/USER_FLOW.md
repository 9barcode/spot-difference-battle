# 사용자 흐름

> 문서 상태: CURRENT
> 기준일: 2026-07-29

## 1. 온라인 기본 흐름

`접속 → 닉네임 설정 → 로비 → 매칭 대기 → 역할 확인·준비 → 제작자 편집/찾는 사람 대기 → 문제 제출 → 찾는 사람 풀이/제작자 관전 → 결과 → 로비`

### 접속과 로비

1. 서버 연결 상태를 확인한다.
2. 닉네임이 없으면 입력하고 저장한다.
3. `빠른 대전` 또는 `1인 테스트 모드`를 선택한다.

### 매칭과 준비

1. 빠른 대전을 선택하면 상대를 찾는 화면으로 이동한다.
2. 먼저 대기열에 들어간 사용자가 제작자, 다음 사용자가 찾는 사람이 된다.
3. 각자 상대 닉네임과 역할을 확인한다.
4. 양쪽이 준비 완료를 누르면 제작 단계로 이동한다.

매칭 중 취소하면 기권 없이 로비로 돌아간다. 현재 매칭 경과 시간과 자동 시간초과는 제공하지 않는다.

### 제작

제작자:

1. 원본 장면과 남은 시간을 확인한다.
2. 서로 다른 객체를 선택하고 색상 또는 모양·무늬 효과를 적용한다.
3. 차이점을 저장·수정·삭제해 정확히 3개를 만든다.
4. `수정 완료`를 눌러 합성된 PNG 문제 이미지와 정답 영역을 제출한다.

찾는 사람:

- 원본과 편집 결과를 받지 않는다.
- 상대가 수정 중이라는 비공개 대기 화면만 확인한다.

마감 3초 전까지 3개를 채우지 못하면 제작자 클라이언트가 장면별 후보로 자동 보충해 제출한다. 자동 제출이 실패하거나 마감까지 제출하지 못하면 제작자가 기권한다.

### 풀이

찾는 사람:

1. 원본과 완성된 문제 이미지를 비교한다.
2. 수정 이미지에서 차이가 있다고 생각하는 위치를 선택한다.
3. 정답이면 발견 수와 표시가 갱신된다.
4. 오답이면 남은 시간이 3초 줄어든다.
5. 필요하면 힌트 1회를 사용한다.
6. 3개를 모두 찾으면 즉시 승리한다.

제작자:

- 풀이에 참여하지 않고 상대의 발견 수와 오답 수를 확인한다.
- 풀이 시간이 끝날 때까지 상대가 완료하지 못하면 승리한다.

### 결과

- 승패와 종료 사유를 확인한다.
- 찾는 사람의 발견 수, 오답과 힌트 사용 여부를 확인한다.
- 처음으로 전체 정답을 확인한다.
- 로비로 돌아가거나 문제를 신고한다.

현재 결과 화면에는 재대전과 즉시 새 매칭이 없다.

## 2. 1인 테스트 흐름

`로비 → 1인 테스트 → 객체 3개 제작 → 편집 화면 숨김 → 직접 풀이 → 결과 → 로비`

1인 모드는 클라이언트에서 동작하며 온라인 매칭, 서버 전적, 신고와 연결되지 않는다. 제작 타이머 없이 편집할 수 있고 풀이 제한시간과 오답 차감은 온라인 규칙과 같은 수치를 사용한다.

## 3. 예외 흐름

### 연결 끊김

- 내 연결 상실: 입력을 차단하고 자동 재연결 오버레이를 표시한다.
- 상대 연결 상실: 10초 동안 복귀를 기다린다는 안내를 표시한다.
- 10초 안에 복귀: 최신 서버 스냅샷을 받아 이어간다.
- 10초 초과: 연결이 끊긴 플레이어가 기권한다.

현재 오버레이에는 초 단위 남은 시간과 수동 재시도 버튼이 없다.

### 직접 이탈

경기 중 나가기는 확인 후 기권 처리한다. 매칭 대기 취소는 기권이 아니다.

### 서버 오류

서버가 승패를 신뢰할 수 없다고 판단하면 경기를 취소하고 전적에 포함하지 않는다.

### 이미지 오류

제작 이미지 생성 실패 시 제작자는 다시 시도할 수 있다. 마감까지 제출하지 못하면 제작자 기권으로 끝난다. 경기 준비 단계의 이미지 로드 실패를 서버가 취소하는 흐름은 아직 구현되지 않았다.

### 신고

완료 또는 취소 화면에서 사유를 고르고 선택적으로 설명을 입력한다. 한 플레이어는 같은 경기를 한 번만 신고할 수 있으며 접수 완료만 안내한다.
