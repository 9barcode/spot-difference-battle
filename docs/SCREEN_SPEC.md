# 화면 명세

> 문서 상태: CURRENT
>
> 기준일: 2026-07-30
> 현재 활성 진입점 `UI/src/main.tsx`가 렌더하는 `MvpApp`을 기준으로 한다.
> 게임 동작은 유일한 규칙 정본 `GAME_RULES.md`를 화면에 매핑한 것이며 이 문서에서 새 규칙을 정의하지 않는다.

## 공통 원칙

- 현재 역할, 단계, 남은 시간과 다음 행동을 명확히 보여준다.
- 정답·오답·경고는 색상과 문구를 함께 사용한다.
- 데스크톱과 모바일에서 정규화 좌표를 유지한다.
- 연결 상실과 처리 중 상태에서는 중복 입력을 막는다.
- 승패에 영향을 주는 행동은 즉각적인 시각 피드백을 제공한다.

청각 피드백은 현재 구현되지 않았으며 접근성 개선 항목으로 관리한다.

## 1. 닉네임과 로비

표시:

- 게임 제목과 설명
- 닉네임 입력 또는 저장된 닉네임
- 서버 연결 상태
- 빠른 대전 버튼
- 1인 테스트 모드 버튼

상태:

- 닉네임 입력·오류
- 서버 연결 중·연결 실패
- 로비

## 2. 매칭 대기

표시:

- 상대를 찾는 중이라는 메시지
- 로딩 표시
- 매칭 취소 버튼

현재 경과 시간, 자동 매칭 시간초과와 시간초과 화면은 없다.

## 3. 준비

표시:

- 상대 닉네임
- 내 역할: 제작자 또는 찾는 사람
- 역할별 간단한 안내
- 준비 완료 버튼과 상대 대기 상태

양쪽 준비 완료 후 제작 단계로 이동한다.

## 4. 제작과 비공개 대기

### 제작자 화면

표시:

- 원본 장면
- 선택 가능한 객체 영역
- 색상과 모양·무늬 효과
- 저장된 차이점 수
- 남은 시간
- 자동 보충 안내
- 문제 이미지 생성·실패·재시도 상태
- 수정 완료 버튼

정본에서 가져온 화면 동작:

- 서로 다른 객체의 유효한 차이점 3개가 있어야 수동 제출할 수 있다.
- 마감 3초 전 부족한 항목을 자동 보충해 제출한다.
- 제출 후 편집할 수 없다.

### 찾는 사람 화면

- 원본과 수정 이미지를 표시하지 않는다.
- 상대가 수정 중이라는 안내와 대기 상태만 표시한다.

## 5. 문제 전달

제작자 제출 승인 시 서버는 `SWAPPING`에서 곧바로 `FINDING`으로 전환한다. 구현에는 처리 중 화면이 있지만 전이가 즉시 일어나 일반적으로 짧게 보이거나 보이지 않는다. 양쪽 제출 대기와 시작 카운트다운은 없다.

## 6. 풀이와 관전

### 찾는 사람

표시:

- 원본 이미지
- 제작자가 제출한 문제 이미지
- 발견 수와 오답 수
- 남은 시간
- 힌트 잔여 횟수
- 정답·오답 피드백
- 이미 발견한 위치와 힌트 영역

입력:

- 수정 이미지 위치 선택
- 힌트 사용
- 경기 나가기

### 제작자

- 상대가 찾고 있다는 안내
- 상대의 발견 수와 오답 수
- 남은 시간
- 경기 나가기

제작자는 문제 이미지와 정답을 알고 있지만 풀이 입력은 할 수 없다.

## 7. 연결 상태

- 내 서버 연결 상실 시 전체 화면 재연결 오버레이로 입력을 차단한다.
- 상대가 `RECONNECTING`이면 10초 복귀 대기 안내를 표시한다.

현재 빠진 요소:

- 실제 남은 유예시간 카운트다운
- 수동 재시도 버튼
- 재접속 실패 후 전용 설명 화면

## 8. 결과와 취소

완료 결과 표시:

- 승리·패배
- 기권 종료 안내
- 찾는 사람의 발견 수와 오답 수
- 힌트 사용 횟수
- 전체 정답과 찾은 곳·놓친 곳
- 로비로 돌아가기
- 문제 신고

취소 결과 표시:

- 취소 사유
- 전적에 포함되지 않는다는 안내
- 로비로 돌아가기
- 문제 신고

현재 빠진 요소:

- 완료 시간과 총 소요 시간
- 재대전
- 결과 화면 즉시 새 매칭
- 정상 경기에서 발생하는 무승부

## 9. 신고

현재 UI는 결과 아래의 사유 선택, 신고 버튼과 브라우저 기본 추가 설명 입력창을 사용한다. 중복 신고를 차단하고 접수 완료 상태를 표시한다.

전용 신고 대화상자, 명시적인 취소 버튼과 운영 처리 안내는 후속 UI 개선 항목이다.

## 10. 구형 시안

`UI/src/app/App.tsx`는 Figma 기반 비활성 시안이다. 차이점 5개, 랭킹, 상점, 시즌 등 현재 MVP에 없는 요소가 포함되어 있으므로 구현 기준으로 사용하지 않는다.
