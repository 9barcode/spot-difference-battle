# 화면 명세

> 문서 상태: CURRENT
> 기준일: 2026-08-04
> 게임 동작은 `GAME_RULES.md`를 따른다.

## 공통 원칙

- 원본과 변경본을 명확하게 표기한다.
- 정답·오답·잠금은 색상뿐 아니라 문구와 형태로 알린다.
- 터치 대상은 모바일 최소 크기를 확보한다.
- 확대·이동 동작과 정답 선택을 구분한다.
- 남은 시간, 완료 문제 수와 현재 발견 수는 항상 확인 가능해야 한다.

## 로비와 매칭

- 닉네임 입력·저장
- 빠른 대전
- 매칭 대기 시간과 취소
- 상대 매칭 완료와 준비 버튼

제작자/찾는 사람 역할 표시는 제거한다. 양쪽 모두 같은 목표 안내를 본다.

## 사전 로드와 카운트다운

- 양쪽 준비 상태
- 이미지 로딩 진행과 실패 안내
- 로드 완료 후 가려진 게임 보드
- 서버 기준 3초 카운트다운

카운트다운 전에 이미지 내용을 노출하지 않는다.

## 경기 화면

필수 요소:

- 원본 이미지
- 변경본 이미지와 선택 입력
- 남은 경기 시간
- 내 완료 문제 수와 현재 발견 수 `0/3`
- 상대 완료 문제 수와 현재 발견 수
- 오답 수와 입력 잠금 피드백
- 현재 문제 번호
- 나가기

정답 3개를 찾으면 짧은 완료 피드백 후 다음 문제로 자동 전환한다. 상대의 정답 위치는 표시하지 않는다.

데스크톱은 두 이미지를 좌우 배치한다. 모바일은 현재 상하 배치를 사용한다. 확대·이동과 빠른 전환은 후속 기능이다. 어떤 배치에서도 변경본 좌표를 정규화해 같은 정답으로 판정한다.

## 결과 화면

- 승리·패배·무승부·취소
- 양쪽 완료 문제 수, 총 발견 수와 오답 수
- 종료 사유와 경기 시간
- 문제별 전체 정답과 자신의 발견 여부는 후속 기능
- 로비로 돌아가기
- 문제 신고

재대전과 즉시 새 매칭은 보류 기능이다.

## 접근성·오류

- 키보드 포커스와 스크린리더 이름
- 입력 잠금 상태 안내
- 확대 상태 안내는 확대 기능 구현 시 추가
- 이미지 로드 실패 재시도 또는 경기 취소
- 재접속 남은 유예시간과 상태 복구
- 연결·서버 오류별 사용자가 취할 행동
