# 화면 명세

## 공통 원칙

- 남은 시간, 현재 단계, 해야 할 행동을 항상 명확히 보여준다.
- 정답, 오답, 경고는 색상만으로 구분하지 않고 아이콘이나 문구를 함께 사용한다.
- 모바일에서도 이미지의 선택 좌표가 정확히 유지되어야 한다.
- 로딩, 연결 끊김, 오류 상태에서는 중복 입력을 막는다.
- 승패에 영향을 주는 행동에는 즉각적인 시각·청각 피드백을 제공한다.

## 1. 시작 및 로비

**목적:** 게임 진입과 매칭 시작

**표시 정보:** 게임 제목, 한 줄 설명, 닉네임, 간단한 게임 방법, 접속 상태

**주요 행동:** 매칭 시작, 게임 방법 확인

**상태:** 기본, 닉네임 오류, 서버 연결 실패, 매칭 불가

## 2. 매칭 대기

**목적:** 상대를 찾는 동안 상태 안내

**표시 정보:** 경과 시간, 대기 메시지, 취소 버튼

**주요 행동:** 매칭 취소

**상태:** 검색 중, 상대 발견, 게임 준비 중, 시간 초과, 오류

## 3. 차이점 제작

**목적:** 원본 이미지에 유효한 차이점 3개 제작

**표시 정보:** 원본 이미지, 제작 도구, 등록 개수, 남은 시간, 제출 버튼, 유효성 안내

**주요 행동:** 도구 선택, 차이점 추가·수정·삭제, 제출

**규칙:** 차이점 3개가 유효해야 제출 버튼을 활성화한다. 제출 후에는 수정할 수 없다.

**상태:** 편집 중, 유효하지 않은 위치, 제출 확인, 상대 제출 대기, 자동 보충 안내

## 4. 문제 교환 및 준비

**목적:** 양쪽의 제출 완료와 풀이 시작을 동기화

**표시 정보:** 준비 메시지, 상대 준비 상태, 짧은 시작 카운트다운

**주요 행동:** 없음

**상태:** 상대 제출 대기, 이미지 처리 중, 시작 카운트다운, 처리 오류

## 5. 차이점 찾기

**목적:** 상대가 만든 차이점 탐색

**표시 정보:** 원본, 수정 이미지, 내 진행도, 상대 진행도, 남은 시간, 힌트 버튼, 오답 횟수

**주요 행동:** 위치 선택, 힌트 사용, 경기 나가기

**규칙:** 수정 이미지에서만 답을 선택한다. 이미 찾은 영역은 표시하고 재선택에 페널티를 주지 않는다. 오답 시 3초 차감 결과를 즉시 보여준다.

**상태:** 기본, 정답, 오답, 힌트 표시, 네트워크 지연, 종료 처리 중

## 6. 연결 끊김 오버레이

**목적:** 일시적인 연결 문제와 복구 기회 안내

**표시 정보:** 재연결 상태, 복귀 제한시간, 경기 처리 원칙

**주요 행동:** 재연결 재시도, 경기가 종료된 경우 로비 이동

오버레이 중에는 게임 입력을 차단하고 서버 상태를 기준으로 복구한다.

## 7. 결과

**목적:** 승패 근거를 설명하고 다음 행동 제공

**표시 정보:** 승·패·무승부, 최종 발견 수, 완료 시간, 오답, 힌트 사용 여부, 모든 차이점 위치

**주요 행동:** 재대전 요청, 새 매칭, 로비 이동, 신고

**상태:** 일반 결과, 상대 이탈, 경기 취소, 재대전 요청·수락·거절·시간 초과

## 8. 신고 확인

**목적:** 불공정하거나 부적절한 문제 접수

**표시 정보:** 신고 대상 경기, 사유 목록, 추가 설명, 처리 안내

**주요 행동:** 제출, 취소

중복 제출을 막고 접수 완료 상태를 명확히 표시한다.
