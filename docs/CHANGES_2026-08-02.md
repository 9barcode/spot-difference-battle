# 변경 요약 — 연구실 출시 이미지 정규화 (2026-08-02)

> 문서 상태: HISTORICAL
> 현재 에셋 조건은 `GAME_ASSETS.md`를 따른다.

## 변경

- 사용자 승인에 따라 AI 재생성이 아닌 결정적 로컬 변환을 사용했다.
- 1024×572 제작 원본의 상·하단 가장자리 픽셀을 각각 2픽셀 확장해 정확한 16:9 캔버스를 만들었다.
- Lanczos3로 1920×1080 PNG 서버 정본을 생성했다.
- PNG와 디코딩 픽셀이 동일한 무손실 WebP·AVIF를 생성했다.
- 웹은 WebP, 서버 검증은 PNG를 사용하도록 분리했다.
- 기존 마스크의 Y좌표와 세로 길이를 572→576 캔버스 변환식으로 보정했다.
- 서버 원본이 PNG 1920×1080인지 확인하는 회귀 테스트를 추가했다.

## 검증 결과

- `pnpm check` 통과
- `pnpm test` 통과: 45개 통과, PostgreSQL 전용 1개 건너뜀
- `pnpm build` 통과: 프로덕션 번들에서 무손실 WebP 사용 확인
- `pnpm e2e` 통과: Chromium·Firefox·WebKit 총 12개 시나리오 통과
- 모바일 연구실 18개 중심점의 최상단 터치 대상 및 실제 3개 편집·제출 흐름 통과
## 사용자 제작 장면 4종 추가

- `cozy-cafe`, `enchanted-forest`, `cyber-city`, `underwater-treasure`를 공유·웹·서버 카탈로그에 함께 등록했다.
- 각 장면에 모바일 선택 가능한 객체 마스크 15개와 자동 보충 후보를 추가했다.
- 서버는 1024×1024 PNG 원본, 웹은 픽셀이 동일한 무손실 WebP를 사용한다.
- 숲과 바다의 수정본을 QA 기준 파일로 보관했다.
- 카페와 도시의 modified/original 제공 파일은 각각 SHA-256까지 동일해 실제 수정점이 없음을 기록했다.
- 네 장면은 플레이 검증용이며, 출시 전 16:9 정본과 전체 마스크 효과 경계 육안 검수가 필요하다.
- 네 장면 각각의 15개 모바일 최상단 터치 대상 검사가 Chromium에서 통과했으며, 기본 전체 E2E 12개도 Chromium·Firefox·WebKit에서 통과했다.
- 네 장면 각각에서 대표 객체 3개를 편집해 PNG로 제출하고 상대 풀이 화면에 진입하는 흐름이 Chromium에서 통과했다.
