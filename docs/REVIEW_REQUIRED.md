# 검토 및 결정 필요 항목

> 문서 상태: CURRENT
> 기준일: 2026-08-31
> 책임 역할: 제품 책임자·기술 책임자·운영 책임자

이 문서는 코드만으로 확정할 수 없거나 외부 검증이 필요한 항목의 단일 대기열이다. `BLOCKER`는 공개 출시 전 필수, `HIGH`는 다음 기능 변경 전 우선 해결, `NORMAL`은 계획에 반영할 항목이다.

## 결정 방법

1. 항목의 질문과 증거를 확인한다.
2. 선택한 결정을 `MVP_DECISIONS.md` 또는 별도 결정 기록에 남긴다.
3. 영향받는 정본·코드·테스트·백로그를 같은 변경에서 갱신한다.
4. 검증 증거와 승인자를 기록한 뒤 이 목록에서 `RESOLVED`로 이동한다.

## 활성 항목

### REV-001 — 승패 판정 구현 단일화

- 우선순위: `HIGH`
- 질문: 프로덕션에서 사용하지 않는 구형 `determineWinner(PlayerResult)`와 `lastCorrectAtMs` 우선순위를 제거할 것인가?
- 증거: 프로덕션 `GameMatch`는 총점→오답 뒤 `completedAtMs` 비교 분기를 포함하지만, 첫 완주 즉시 종료 때문에 정상 제한시간 경로에서는 양쪽 미완주 시 무승부다. 별도 공개 함수는 발견 수→오답→마지막 정답 시각을 사용하며 해당 단위 테스트 외 사용되지 않는다.
- 권고: 구형 공개 함수와 `PlayerResult`를 제거하고 내부의 도달 불가능한 완료 시각 분기도 정본에 맞게 정리한 뒤 실제 경기 판정 테스트만 유지한다. 완료 시 `GAME-005`를 검증 상태로 승격한다.
- 결정권자: 기술 책임자

### REV-002 — 구형 장면 식별자 계약 제거

- 우선순위: `HIGH`
- 질문: `GAME_SCENE_IDS`, `GameSceneId`, `GAME_SCENE_ID` 환경변수와 스냅샷 `imageId`를 현재 `GamePuzzleId` 계약으로 전환할 것인가?
- 증거: 공유 장면 목록은 현재 16개 활성 문제 전체를 포함하지 않으며 `GameMatch`가 현재 문제 ID를 `GameSceneId`로 강제 캐스팅한다. 서버 시작 환경변수도 구형 장면 목록을 검사한다.
- 권고: 소비자와 저장 호환성을 조사한 뒤 현재 문제 ID·버전을 명시하는 계약으로 단계적 전환한다.
- 결정권자: 기술 책임자

### REV-003 — 저장소 경로 단일화

- 우선순위: `HIGH`
- 질문: `Battle game` 상위 Git 저장소와 실제 게임 저장소 `.analysis-repo`/`repo-edit` 중 어느 경로를 공식 작업 루트로 유지할 것인가?
- 증거: 상위 `master`는 과거 프로젝트 파일 전체가 삭제 상태이고 실제 게임은 별도 Git 저장소에 있다. 도구에 따라 잘못된 저장소에서 커밋할 위험이 있다.
- 권고: 현재 게임 저장소를 백업·원격 확인 후 명확한 단일 폴더로 이동하고, 상위 저장소 정리는 별도 승인 작업으로 수행한다.
- 결정권자: 저장소 소유자

### REV-004 — 공개 출시 모드 범위

- 우선순위: `BLOCKER`
- 질문: 첫 공개 출시에서 기본전만 노출할지, 속도전·생존전도 함께 출시할지 결정해야 한다.
- 증거: 세 모드는 구현됐으나 난이도별 콘텐츠 양과 실제 플레이 밸런스 데이터가 부족하다.
- 권고: 스테이징 플레이 데이터가 쌓일 때까지 기본전을 기본 공개 범위로 두고 나머지는 실험 기능으로 분리한다.
- 결정권자: 제품 책임자

### REV-005 — 콘텐츠 출시 기준

- 우선순위: `BLOCKER`
- 질문: 난이도별 최소 문제 수와 한 경기 덱 크기를 확정해야 한다.
- 증거: 활성 16세트지만 난이도 풀은 EASY 11, NORMAL 6, HARD 3이다. 현재 서버는 선택 난이도의 전체 풀을 섞어 경기 덱으로 사용한다.
- 권고: 각 공개 난이도 최소 10세트, 문제 반복 없음, 모바일 QA 100%를 최소 기준으로 승인한다. 충족되지 않은 난이도는 비공개로 둔다.
- 결정권자: 제품 책임자·콘텐츠 책임자

### REV-006 — 문제 에셋 권리 승인

- 우선순위: `BLOCKER`
- 질문: `USER_SUPPLIED` 16세트의 생성 도구, 원본 증빙, 상업 이용·재배포 조건을 누가 최종 승인할 것인가?
- 증거: 매니페스트는 제공 경로와 해시를 기록하지만 제3자 법률 검증을 뜻하지 않는다.
- 권고: 문제별 증빙을 `PUZZLE_QA` 기록에 연결하고 권리 책임자가 서명한 항목만 공개 출시한다.
- 결정권자: 프로젝트 소유자 또는 권리 책임자

### REV-007 — 개인정보와 데이터 보존

- 우선순위: `BLOCKER`

- 증거: 저장 구조는 있으나 저장 기간과 개인정보 고지가 문서화되지 않았다.
- 권고: 최소 수집, 목적별 보존 기간, 접근 권한, 삭제·익명화 절차를 공개 출시 전에 승인한다.
