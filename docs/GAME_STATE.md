# 게임 상태

> 문서 상태: CURRENT
>
> `GAME_RULES.md`를 서버 상태 전이로 매핑한 문서다.

| 상태 | 양쪽 플레이어 행동 | 종료 조건 |
|---|---|---|
| `READY` | 준비, 나가기 | 양쪽 준비 |
| `FINDING` | 좌우 그림 선택, 힌트, 나가기 | 양쪽 완료, 찾기 마감, 기권 |
| `FINISHED` | 결과 비교, 로비, 신고 | 로비 이동 |
| `CANCELLED` | 취소 사유 확인, 로비, 신고 | 로비 이동 |

정상 전이는 `READY → FINDING → FINISHED`다.

- `READY`: 양쪽 플레이어가 준비하면 시스템 문제로 즉시 풀이를 시작한다.
- `FINDING`: 두 플레이어가 같은 문제를 푼다. 한쪽 완료만으로 종료하지 않으며 양쪽 완료 또는 마감에 결과를 비교한다.
- 발견 표시와 종료 후 정답 공개는 항상 뷰어 기준으로 생성한다.
- 상태 버전과 서버 마감 시각이 입력 승인과 재접속 복원의 기준이다.
