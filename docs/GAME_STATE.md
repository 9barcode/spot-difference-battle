# 게임 상태

> 문서 상태: CURRENT
> 기준일: 2026-08-22
> 승패와 수치는 `GAME_RULES.md`를 따른다.

## 1. 상태

| 상태 | 의미 | 종료 조건 |
|---|---|---|
| `LOBBY` | 닉네임 설정과 대전 진입 | 매칭 요청 |
| `MATCHING` | 상대 검색 | 두 명 매칭 또는 취소 |
| `READY` | 양쪽 참가와 준비 확인 | 양쪽 준비 완료 또는 30초 시간초과 |
| `PRELOADING` | 문제 순서·버전 확정과 이미지 사전 로드 | 양쪽 첫 문제 로드 완료 또는 실패 |
| `COUNTDOWN` | 문제를 가린 3초 시작 대기 | 서버 시작 시각 도달 |
| `PLAYING` | 양쪽이 독립적으로 차이를 찾고 다음 문제로 이동 | 양쪽 전체 완료, 제한시간, 기권 또는 오류 |
| `FINISHED` | 최종 점수와 승패 공개 | 로비 이동 |

정상 흐름은 `LOBBY → MATCHING → READY → PRELOADING → COUNTDOWN → PLAYING → FINISHED`다.

## 2. 입력 권한

`PLAYING`에서는 위치 선택과 나가기를, `FINISHED`에서는 로비 이동과 신고를 허용한다. 두 플레이어의 권한은 같으며 제작·편집·자동 보충과 경쟁전 힌트 입력은 없다.

## 3. 플레이어별 진행

- 현재 문제 인덱스와 `pairId`·에셋 버전
- 현재 문제 발견 수와 해당 문제의 실제 정답 수
- 완료 문제 수, 총 발견 수와 경기 전체 실제 정답 수
- 정답 점수, 완주 시간 가산점과 총점
- 오답 수와 입력 잠금 종료 시각
- 전체 완료 여부와 서버 기준 완료 시각
- 이미지 로드 및 연결 상태

한 플레이어가 문제를 완료하면 해당 플레이어만 다음 문제로 이동한다. 한 명만 전체 문제를 완료한 경우 상태는 `PLAYING`으로 유지되어 상대가 계속 풀 수 있다. 두 명 모두 전체 문제를 완료하면 즉시 `FINISHED`로 전환한다.

## 4. 마감과 결과

- 준비·프리로드 실패는 `CANCELLED`다.
- 양쪽 전체 완료 또는 제한시간 도달 시 서버가 점수, 오답, 완료 시각 순서로 승패를 판정한다.
- 직접 이탈 또는 재접속 유예 초과는 상대 기권승이다.
- 서버가 상태를 신뢰할 수 없으면 `CANCELLED`다.

## 5. 공개 범위

경기 중에는 자신의 이미지 쌍·발견 위치·오답과 양쪽의 현재 문제 번호, 현재 발견/실제 정답 수, 전체 발견/실제 전체 정답 수, 공통 마감 시각을 공개한다. 상대가 찾은 정확한 좌표와 미발견 정답은 비공개다. `FINISHED`에서 양쪽 최종 점수와 진행을 공개한다.

## 6. 동시성

서버가 경기 상태와 플레이어별 진행 버전을 관리한다. 동일 정답 중복 요청은 한 번만 반영하고 입력 잠금 중 요청과 마감 이후 요청은 거절한다. 재접속 시 서버 스냅샷으로 현재 진행과 완료 시점을 복구한다.
