# 게임 상태 정의

## 1. 상태 원칙

- 서버가 경기 상태의 최종 권한을 가진다.
- 클라이언트는 서버가 허용한 상태에서만 입력을 보낸다.
- 모든 상태 변경에는 경기 ID, 상태 버전, 서버 시간이 포함되어야 한다.
- 재접속 시 클라이언트는 로컬 상태를 이어 쓰지 않고 서버의 최신 상태를 다시 받는다.

## 2. 주요 상태

| 상태 | 의미 | 주요 종료 조건 |
|---|---|---|
| `LOBBY` | 매칭 전 대기 | 사용자가 매칭 시작 |
| `MATCHING` | 상대 검색 및 입장 대기 | 두 플레이어 연결 또는 취소 |
| `READY` | 이미지 로드와 시작 준비 | 양쪽 준비 완료 |
| `EDITING` | 차이점 제작 | 양쪽 제출 또는 제한시간 종료 |
| `SWAPPING` | 문제 검증·교환 | 양쪽 문제 준비 완료 |
| `FINDING` | 상대 문제 풀이 | 전부 발견 또는 제한시간 종료 |
| `FINISHED` | 결과 확정 | 재대전, 새 매칭, 로비 이동 |
| `CANCELLED` | 승패 없이 경기 취소 | 결과 안내 후 이동 |

## 3. 보조 연결 상태

연결 상태는 경기 상태와 별도로 관리한다.

- `CONNECTED`: 정상 연결
- `DISCONNECTED`: 연결 상실 감지
- `RECONNECTING`: 복귀 유예시간 안에 재연결 시도
- `FORFEITED`: 직접 이탈 또는 유예시간 초과

연결이 끊겨도 서버의 경기 타이머는 계속 흐른다. 10초의 유예시간 안에 복귀하지 않으면 해당 플레이어를 `FORFEITED`로 처리한다.

## 4. 상태 전이

### 정상 전이

`LOBBY → MATCHING → READY → EDITING → SWAPPING → FINDING → FINISHED`

### 재대전

`FINISHED → READY`

재대전은 양쪽이 동의하고 새 경기 ID가 발급된 경우에만 진행한다.

### 취소

- `MATCHING → LOBBY`: 사용자가 대기 취소
- `MATCHING → CANCELLED`: 상대 입장 시간 초과
- `READY → CANCELLED`: 이미지 준비 실패
- `EDITING → CANCELLED`: 서버가 문제 제작을 처리할 수 없음
- `SWAPPING → CANCELLED`: 문제 검증 또는 교환 실패
- `FINDING → CANCELLED`: 승패를 신뢰할 수 없는 서버 오류

## 5. 상태별 허용 입력

| 상태 | 허용 입력 |
|---|---|
| `LOBBY` | 매칭 시작, 게임 방법 확인 |
| `MATCHING` | 매칭 취소 |
| `READY` | 준비 완료 |
| `EDITING` | 차이점 추가·수정·삭제, 제출 |
| `SWAPPING` | 없음 |
| `FINDING` | 위치 선택, 힌트 사용, 나가기 |
| `FINISHED` | 재대전, 새 매칭, 로비, 신고 |
| `CANCELLED` | 새 매칭, 로비 |

상태에 맞지 않거나 이전 상태 버전을 기준으로 한 입력은 서버가 거절한다.

## 6. 종료 판정

서버는 정답 수, 오답 수, 정답 처리 시각을 기록하고 `GAME_RULES.md`의 우선순위에 따라 결과를 한 번만 확정한다. `FINISHED` 이후 도착한 풀이 입력은 결과에 반영하지 않는다.
