# 게임 규칙

> 문서 상태: CURRENT — 현재 게임 규칙의 유일한 Markdown 정본
>
> 수치의 실행 기준은 `packages/shared/src/index.ts`의 `GAME_CONFIG`다.

## 1. 기본 구성

- 한 경기는 서로 다른 두 플레이어로 구성한다.
- 두 플레이어 모두 문제 제작자이자 상대 문제의 풀이자다.
- 차이점은 각자 3개, 제작 시간은 30초, 찾기 시간은 60초다.
- 오답 1회마다 본인의 남은 시간이 3초 줄고, 힌트는 각자 한 번 사용할 수 있다.
- 연결이 끊기면 10초 동안 복귀를 기다린 뒤 기권 처리한다.

## 2. 준비와 제작

양쪽이 준비하면 동시에 `EDITING`으로 이동한다. 각 플레이어는 서로 다른 객체 3개를 수정해 정답 정보와 합성 PNG를 제출한다. 서버는 객체, 정답 영역, 이미지 형식·용량·좌표 일치를 검증한다.

제작 중에는 상대의 수정 이미지, 선택 객체와 정답 좌표를 절대 전달하지 않는다. 먼저 제출한 플레이어는 상대 제출이 끝날 때까지 기다린다. 마감 직전에는 클라이언트가 부족한 차이점을 자동 보충해 제출할 수 있다.

한쪽만 마감까지 제출하지 못하면 제출한 플레이어가 기권승한다. 양쪽 모두 미제출이면 승자 없이 종료한다.

## 3. 문제 교환과 찾기

양쪽 제출이 승인되면 `SWAPPING`을 거쳐 `FINDING`으로 이동한다. 각 플레이어에게는 상대가 합성한 문제 이미지 한 장만 전달한다. 제작 명령과 미발견 정답 좌표는 공개하지 않는다.

두 플레이어는 같은 60초 동안 동시에 상대 문제를 푼다. 처음 맞힌 정답만 발견 수에 추가하며, 이미 찾은 정답을 다시 누르는 것은 오답으로 처리하지 않는다. 정답이 아닌 선택은 오답 수를 늘리고 3초를 차감한다.

한 플레이어가 먼저 3개를 찾아도 경기는 즉시 끝나지 않고 상대 완료 또는 공통 마감까지 기다린다. 완료한 플레이어의 추가 입력은 결과를 바꾸지 않는다.

## 4. 승패

양쪽 완료 또는 찾기 마감 시 다음 순서로 비교한다.

1. 발견 수가 많은 플레이어
2. 발견 수가 같으면 오답이 적은 플레이어
3. 위 조건도 같으면 마지막 정답 시각이 빠른 플레이어
4. 모든 조건이 같으면 무승부

직접 이탈 또는 재접속 제한시간 초과는 상대의 기권승이다. 서버 오류로 결과를 신뢰할 수 없으면 `CANCELLED`로 처리한다.

## 5. 결과와 신고

경기 종료 후 각 플레이어에게 상대 문제의 전체 정답과 본인이 찾은 곳·놓친 곳을 공개한다. 결과 화면은 양쪽의 발견 수와 오답 수, 승패와 종료 사유를 비교해 표시한다.

완료되거나 취소된 경기에서 플레이어당 한 번 신고할 수 있다. 신고 사유는 불공정, 부적절한 표현, 시스템 오류, 기타다.
