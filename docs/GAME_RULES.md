# 게임 규칙

> 문서 상태: CURRENT — 게임 판정의 최우선 문서
>
> 기준일: 2026-07-29
> 수치의 실행 기준은 `packages/shared/src/index.ts`의 `GAME_CONFIG`다.

## 1. 기본 구성

- 한 경기는 서로 다른 두 플레이어로 구성한다.
- 먼저 매칭된 플레이어는 `제작자`, 두 번째 플레이어는 `찾는 사람`이다.
- 차이점은 3개다.
- 제작 제한시간은 30초, 찾기 제한시간은 60초다.
- 오답 1회마다 찾는 사람의 남은 시간이 3초 줄어든다.
- 힌트는 찾는 사람만 경기당 1회 사용할 수 있다.
- 연결이 끊기면 10초 동안 복귀를 기다린 뒤 기권 처리한다.

## 2. 준비

두 플레이어가 모두 준비해야 제작 단계로 이동한다. 현재 장면 ID는 서버가 경기 생성 시 정하고, 재접속과 서버 재시작 복구 시 같은 ID를 유지한다.

현재는 이미지 로드 완료를 별도 서버 승인으로 확인하지 않는다. 이미지 로드 실패와 준비 시간초과는 미완료 예외 처리 항목이다.

## 3. 차이점 제작

- 제작자만 문제를 만들고 제출할 수 있다.
- 찾는 사람은 제작 중 원본·수정본·객체 선택·정답 좌표를 받지 않는다.
- 제작자는 장면 카탈로그에 정의된 서로 다른 객체 3개를 선택한다.
- 객체에는 색상 변경 또는 지원되는 모양·무늬 효과를 적용한다.
- 정답 영역은 정규화 좌표를 사용하고 크기·경계·최소 간격 검사를 통과해야 한다.
- 차이점 3개와 합성된 PNG 문제 이미지가 모두 유효해야 제출할 수 있다.
- 제출 후에는 수정할 수 없다.

서버는 장면별 허용 객체 ID와 효과 목록을 독립적으로 검사한다. 등록되지 않은 객체, 같은 객체의 중복 제출, 허용되지 않은 효과와 객체 편집 정보가 없는 제출은 거절한다.

마감 3초 전까지 차이점이 부족하면 제작자 클라이언트가 장면별 후보로 자동 보충해 제출을 시도한다. 마감까지 유효한 제출이 없으면 제작자가 기권하고 찾는 사람이 승리한다.

## 4. 문제 전달

제작자 클라이언트가 완성된 문제 이미지를 합성한다. 서버는 제출 데이터와 문제 이미지를 검증하고 찾는 사람에게 렌더된 이미지 한 장만 전달한다.

제작 명령과 미발견 정답 좌표는 풀이 중 찾는 사람에게 보내지 않는다. 제작자 제출이 승인되면 `SWAPPING`을 내부적으로 거쳐 즉시 찾기 단계가 시작된다. 별도의 양쪽 제출 대기나 시작 카운트다운은 없다.

## 5. 차이점 찾기

- 찾는 사람만 정답 선택과 힌트 사용이 가능하다.
- 답은 수정 이미지에서 선택한다.
- 서버는 원본 기준 정규화 좌표와 정답 영역으로 판정한다.
- 처음 맞힌 정답만 발견 수에 추가한다.
- 이미 찾은 정답을 다시 선택해도 오답이나 시간 차감으로 처리하지 않는다.
- 정답이 아닌 선택은 오답 수를 1 올리고 남은 시간을 3초 줄인다.
- 힌트는 아직 찾지 못한 정답 중 하나의 주변 영역을 알려준다.
- 마감 이후 입력과 이전 상태 버전의 입력은 결과에 반영하지 않는다.

## 6. 승패

1. 찾는 사람이 60초 안에 3개를 모두 찾으면 찾는 사람이 승리한다.
2. 찾기 시간이 끝날 때까지 모두 찾지 못하면 제작자가 승리한다.
3. 제작자가 제작 마감까지 제출하지 못하면 찾는 사람이 기권승한다.
4. 플레이어가 직접 나가거나 재접속 유예시간을 넘기면 상대가 기권승한다.
5. 서버가 결과를 신뢰할 수 없는 오류는 승패 없이 `CANCELLED`로 처리한다.

정상적인 현재 경기 흐름에는 점수 비교 동점 판정이나 무승부가 없다. `winnerId = null`은 취소와 호환 가능한 데이터 표현을 위해 남아 있지만 정상 시간 종료 판정으로 사용하지 않는다.

## 7. 결과와 공개

경기가 끝난 뒤에만 전체 정답 위치를 양쪽에 공개한다. 찾은 곳과 놓친 곳을 구분하고, 찾는 사람의 발견 수·오답 수·힌트 사용 여부와 종료 사유를 표시한다.

현재 제공 행동:

- 로비로 돌아가기
- 문제 신고

재대전과 결과 화면의 새 매칭은 후속 기능이다.

## 8. 신고

완료되거나 취소된 경기에서 플레이어당 한 번 신고할 수 있다. 사유는 불공정, 부적절한 표현, 시스템 오류, 기타다. 신고는 저장만 하며 자동 제재하지 않는다.

현재 완료 경기에는 문제 이미지와 정답 좌표가 영구 보관되지 않으므로 운영자가 신고 대상을 재검토할 수 있도록 저장 구조를 보완해야 한다.
