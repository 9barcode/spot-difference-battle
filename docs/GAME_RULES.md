# 게임 규칙

> 문서 상태: CURRENT
>
> 기준일: 2026-08-22

역할, 행동 권한, 수치, 시간, 승패, 기권, 정보 공개와 신고 조건은 이 문서에서만 정의한다.

## 1. 게임 목표

두 플레이어가 동일한 원본과 변경본을 비교해 차이점을 빠르게 찾는다. 한 문제의 실제 차이점을 모두 찾으면 각자 즉시 다음 문제로 이동한다. 한 명만 전체 문제를 완료하면 상대가 계속 풀 수 있지만, 두 명 모두 전체 문제를 완료하면 남은 시간을 기다리지 않고 경기를 끝낸다.

- 두 플레이어 모두 `찾는 사람`이며 제작자 역할은 없다.
- 서버는 두 플레이어에게 같은 순서의 검증된 문제 세트를 제공한다.
- 문제별 차이점 수는 고정하지 않고 문제 데이터에 등록된 실제 정답 영역 수를 사용한다.
- 제한시간은 기본전 180초, 속도전 60초, 생존전 120초다.
- 준비 제한시간은 30초, 시작 카운트다운은 3초다.
- 경쟁전에는 힌트가 없다.
- 오답 잠금은 쉬움 0.5초, 보통 1초, 어려움 2초다. 생존전은 누적 오답 3회에 도달하면 패배한다.
- 연결이 끊기면 10초 동안 복귀를 기다린 뒤 기권 처리한다.

## 2. 문제 세트

각 문제는 고유한 `pairId`와 버전, 같은 크기·비율·구도의 원본과 변경본, 하나 이상의 검수된 정답 영역을 가져야 한다. 정답 영역은 정규화 좌표로 등록하고 이미지와 함께 해시 또는 버전을 추적한다. 라이선스와 이용 조건도 확인한다.

문제별 정답 수는 달라질 수 있다. 전체 경기 정답 수는 경기 문제 목록의 실제 정답 영역 수를 합산한다. 생성형 편집의 영역 밖 미세 픽셀 차이는 자동 정답으로 취급하지 않는다.

## 3. 준비와 시작

1. 두 플레이어가 매칭되고 준비한다.
2. 서버가 경기용 문제 순서와 버전을 확정한다.
3. 양쪽 클라이언트가 첫 문제와 다음 문제를 미리 불러온다.
4. 양쪽의 첫 문제 로드 완료를 서버가 확인한다.
5. 서버 기준 3초 카운트다운 후 동시에 경기를 시작한다.

로드 실패와 준비 시간초과는 승패가 아닌 `CANCELLED`로 처리한다.

## 4. 차이점 찾기

- 플레이어는 변경본 이미지에서 답을 선택하고 서버가 판정한다.
- 처음 맞힌 정답만 발견 수에 추가한다. 이미 찾은 영역의 재선택은 오답으로 처리하지 않는다.
- 정답이 아닌 선택은 오답 수를 1 올리고 선택한 난이도의 입력 잠금을 적용한다.
- 현재 문제에 등록된 실제 정답을 모두 찾으면 해당 문제를 완료하고 즉시 다음 문제로 이동한다.
- 입력 잠금 중 요청, 마감 이후 요청과 현재 상태·문제가 다른 요청은 반영하지 않는다.

상대에게는 현재 문제 번호, 현재 문제에서 찾은 수와 실제 정답 수, 전체 발견 수와 전체 정답 수를 보여준다. 상대가 찾은 정확한 위치와 미공개 정답은 보여주지 않는다.

## 5. 점수와 승패

- 정답 발견 점수: 1개당 10점
- 완주 시간 가산점: 전체 문제를 완료한 시점의 남은 시간 1초당 0.5점
- 총점: `총 발견 수 × 10 + 완주 시 남은 초 × 0.5`
- 시간 가산점은 소수 첫째 자리까지 표시한다.

한 명만 전체 문제를 완료하면 상대가 남은 문제를 계속 푼다. 두 명 모두 완료하면 즉시 종료한다. 정상 종료의 승패 우선순위는 다음과 같다.

1. 총점이 높은 플레이어
2. 총점이 같으면 오답이 적은 플레이어
3. 오답도 같으면 전체 문제를 먼저 완료한 플레이어
4. 모두 같으면 무승부

기권과 생존전 오답 한도 종료는 해당 규칙의 승패를 우선한다.

## 6. 시간과 공정성

경기 시작·종료·입력 잠금·완료 시점은 서버 시각으로 판정한다. 서버가 같은 문제 순서와 버전을 제공하고 유효 입력을 승인하며, 클라이언트가 보낸 점수나 정답 여부는 신뢰하지 않는다.

## 7. 이탈과 오류

- 직접 이탈 또는 10초 재접속 유예 초과는 상대 기권승이다.
- 짧은 재접속 중에도 서버 경기 시간은 흐른다.
- 양쪽이 모두 이탈하거나 서버가 결과를 신뢰할 수 없으면 `CANCELLED`다.

## 8. 결과와 공개

결과 화면에는 승패·무승부·취소, 종료 사유, 양쪽의 `완료 · 발견 수/실제 전체 정답 수`, 총점, 정답 점수, 시간 가산점과 오답 수를 표시한다. 문제 신고를 제공하며 전체 정답 검토는 후속 기능이다.

## 9. 후속 1인 연습

후속 1인 모드는 같은 문제 세트를 사용하되 온라인 전적과 신고에는 포함하지 않는다.

## 10. 신고

완료되거나 취소된 경기에서 플레이어당 한 번 신고할 수 있다. 운영 검토를 위해 문제 순서, 버전, 이미지 해시, 정답 영역과 입력 결과를 보존한다.
