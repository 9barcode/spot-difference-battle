# 틀린그림찾기 배틀 — 게임 규칙 v0.1

## 게임 목표

두 플레이어가 동일한 원본 그림을 받아 각자 차이점 3개를 만든다. 이후 서로가 만든 문제를 교환하고, 제한시간 안에 상대방의 차이점을 먼저 모두 찾는 플레이어가 승리한다.

## 기본 구성

- 플레이 인원: 2명
- 게임 방식: 실시간 1대1 대전
- 차이점 개수: 플레이어당 3개
- 차이점 제작시간: 30초
- 차이점 찾기 시간: 60초
- 기본 힌트: 경기당 1회
- 오답 페널티: 남은 시간 3초 차감

초기 테스트에서는 빠르게 한 판을 완주하고 핵심 재미를 검증할 수 있도록 차이점을 3개로 제한한다.

## 게임 진행

### 1. 매칭

- 두 플레이어를 연결하고 동일한 원본 그림을 제공한다.
- 상대방이 정해진 시간 안에 입장하지 않으면 매칭을 취소한다.

### 2. 차이점 제작

각 플레이어는 30초 동안 다음 방식으로 차이점 3개를 만든다.

- 스티커 또는 작은 사물 추가
- 원본 사물 일부 가리기
- 지정된 부분의 색상 변경

차이점은 서로 겹칠 수 없으며 일정한 최소 거리를 두어야 한다. 화면 가장자리, 지나치게 작은 변경, 거의 보이지 않는 변경, 같은 위치의 중복 등록은 허용하지 않는다. 차이점 3개를 만들어야 제출할 수 있다.

초기 테스트에서는 제한시간이 끝나기 직전에 완성하지 못한 차이점을 시스템이 자동으로 추가하여 제출한다. 자동 보충까지 실패해 아무것도 제출하지 못한 플레이어는 기권으로 처리하고, 양쪽 모두 제출하지 못하면 승패 없이 경기를 취소한다.

### 3. 문제 교환

두 플레이어가 제작을 완료하면 서로의 수정된 그림을 교환한다. 자신이 만든 문제는 풀이 단계에서 볼 수 없다.

교환되는 것은 완성된 그림 한 장뿐이다. 상대가 어떤 방식으로 무엇을 바꿨는지에 대한 정보는 경기가 끝날 때까지 전달되지 않는다.

### 4. 차이점 찾기

- 원본과 상대방이 수정한 그림을 비교한다.
- 수정된 그림에서 차이가 있다고 생각하는 위치를 선택한다.
- 정답 영역을 선택하면 정답으로 처리한다.
- 이미 찾은 정답을 다시 선택해도 점수는 증가하지 않는다.
- 오답을 선택하면 남은 시간이 3초 감소한다.
- 찾은 차이는 화면에 표시하여 중복 선택을 방지한다.
- 상대방이 찾은 개수는 보여주되 정확한 위치는 공개하지 않는다.

## 힌트

- 한 경기에서 1회 사용할 수 있다.
- 아직 찾지 못한 차이점 하나의 주변 영역을 약 2초 동안 표시한다.
- 정확한 정답 위치를 직접 공개하지 않는다.
- 이미 찾은 차이점은 힌트 대상으로 선택하지 않는다.

초기 버전에서는 힌트 사용에 재화를 요구하지 않는다.

## 승리 조건

다음 우선순위로 승자를 결정한다.

1. 차이점 3개를 먼저 찾은 플레이어가 즉시 승리한다.
2. 시간이 끝나면 더 많은 차이점을 찾은 플레이어가 승리한다.
3. 찾은 개수가 같으면 오답이 적은 플레이어가 승리한다.
4. 오답 수도 같으면 마지막 정답을 더 빨리 찾은 플레이어가 승리한다.
5. 모든 조건이 같으면 무승부로 처리한다.

네트워크 지연으로 인한 불공정을 막기 위해 서버에 기록된 정답 시간을 기준으로 판정한다.

## 이탈 및 연결 끊김

- 플레이어가 직접 나가면 기권패로 처리한다.
- 연결이 끊기면 10초 동안 재접속을 기다린다.
- 10초 안에 복귀하면 기존 경기 상태를 이어간다.
- 복귀하지 않으면 해당 플레이어의 패배로 처리한다.
- 서버 문제로 경기가 중단되면 승패 없이 취소한다.

## 경기 종료

결과 화면에는 승패, 최종 점수, 차이점별 정답 여부, 소요 시간, 오답 횟수, 힌트 사용 여부와 상대방이 만든 전체 차이점을 표시한다.

경기 종료 후 플레이어는 다음 행동을 선택할 수 있다.

- 같은 상대와 재대전
- 새로운 상대 찾기
- 로비로 이동
- 부적절하거나 불공정한 문제 신고

## 공정성 원칙

다음과 같은 문제 제작은 허용하지 않는다.

- 눈으로 구분하기 어려울 정도로 작은 변경
- 이미지 바깥이나 가장자리에 숨긴 차이점
- 서로 겹치는 차이점
- 배경과 거의 구분되지 않는 변경
- 정답으로 등록되지 않은 시각적 변경
- 부적절하거나 공격적인 이미지 또는 스티커
- 시스템 오류를 이용하여 찾을 수 없게 만든 문제

반복적으로 불공정한 문제를 만드는 사용자는 경고 또는 이용 제한 대상이 된다.

## 초기 테스트 목표

- 사용자가 30초 안에 차이점 3개를 만들 수 있는가?
- 차이점을 만드는 과정 자체가 재미있는가?
- 상대방이 만든 문제가 공정하다고 느껴지는가?
- 60초의 풀이시간과 오답 3초 차감이 적절한가?
- 한 판이 끝난 후 다시 플레이하고 싶은가?

테스트 결과에 따라 차이점 개수, 제작시간, 풀이시간과 오답 페널티를 조정한다.
