# 게임 규칙

> 문서 상태: CURRENT — 현재 게임 규칙의 유일한 Markdown 정본
>
> 수치의 실행 기준은 `packages/shared/src/index.ts`의 `GAME_CONFIG`다.

## 1. 기본 구성

- 한 경기는 서로 다른 두 플레이어로 구성한다.
- 두 플레이어는 시스템이 선택한 동일한 원본·오류 그림을 동시에 푼다.
- 차이점은 3개, 찾기 시간은 60초다.
- 오답 1회마다 본인의 남은 시간이 3초 줄고, 힌트는 각자 한 번 사용할 수 있다.
- 연결이 끊기면 10초 동안 복귀를 기다린 뒤 기권 처리한다.

## 2. 준비와 찾기

양쪽이 준비하면 제작·제출 단계 없이 즉시 `FINDING`으로 이동한다. 원본과 오류 그림은 동일한 좌표계를 공유하므로 어느 쪽의 같은 위치를 눌러도 서버가 동일한 정답으로 판정한다.

처음 맞힌 정답만 발견 수에 추가하며, 이미 찾은 정답을 다시 누르는 것은 오답으로 처리하지 않는다. 정답이 아닌 선택은 오답 수를 늘리고 3초를 차감한다.

한 플레이어가 먼저 3개를 찾아도 경기는 즉시 끝나지 않고 상대 완료 또는 공통 마감까지 기다린다. 완료한 플레이어의 추가 입력은 결과를 바꾸지 않는다.

## 3. 승패

양쪽 완료 또는 찾기 마감 시 다음 순서로 비교한다.

1. 발견 수가 많은 플레이어
2. 발견 수가 같으면 오답이 적은 플레이어
3. 위 조건도 같으면 마지막 정답 시각이 빠른 플레이어
4. 모든 조건이 같으면 무승부

직접 이탈 또는 재접속 제한시간 초과는 상대의 기권승이다. 서버 오류로 결과를 신뢰할 수 없으면 `CANCELLED`로 처리한다.

## 4. 결과와 신고

경기 종료 후 각 플레이어에게 전체 정답과 본인이 찾은 곳·놓친 곳을 공개한다. 결과 화면은 양쪽의 발견 수와 오답 수, 승패와 종료 사유를 비교해 표시한다.

완료되거나 취소된 경기에서 플레이어당 한 번 신고할 수 있다. 신고 사유는 불공정, 부적절한 표현, 시스템 오류, 기타다.
