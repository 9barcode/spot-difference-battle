## 2. 성공 조건

- 두 브라우저가 동일한 문제 순서로 동시에 시작한다.
- 각 플레이어가 독립적으로 문제를 완료하고 다음 문제로 이동한다.
- 첫 전체 완주 또는 제한시간 종료 시 양쪽에 같은 점수와 승패가 표시된다.
- 정답 영역과 상대의 발견 위치가 경기 종료 전에 노출되지 않는다.
- 이미지 로딩 속도가 경기 시간과 순위에 영향을 주지 않는다.
- 데스크톱과 모바일의 정규화 좌표가 같은 답으로 처리된다.
- 문제 이미지, 등록된 실제 정답 수, 라이선스와 버전을 운영자가 재검토할 수 있다.

## 3. 보류 기능

- 문제별 선착순 보너스와 경쟁전 힌트
- 재대전과 결과 화면 즉시 새 매칭
- 계정, 랭킹, 시즌, 친구, 채팅, 관전과 리플레이
- 사용자 이미지 업로드
- 재화, 상점과 결제

## 5. 결정 근거

경기 중 이미지를 수정하면 생성 품질, 화풍 일치, 모바일 편집 난이도와 상대 대기 시간이 결과에 영향을 준다. 미리 만든 이미지 쌍을 검수하면 차이 개수와 난이도를 통제할 수 있다.

문제마다 상대를 기다리면 빠른 플레이의 보상이 약해진다. 각자 완료 즉시 다음 문제로 이동하되 같은 문제 순서를 사용한다.

문제를 먼저 완료한 플레이어는 이미 다음 문제를 먼저 시작한다. 선착 추가 점수는 같은 행동을 두 번 보상하므로 사용하지 않는다.

생성형 편집에는 의도하지 않은 미세 픽셀 변화가 생길 수 있다. 자동 픽셀 비교 대신 제작자가 의도한 정답 영역을 등록하고 사람이 검수한다.
