- 과거 `CHANGES_*.md`와 릴리스의 당시 규칙 설명은 역사 기록으로 유지했다.

## 현재 확정 규칙

- 두 플레이어는 같은 문제 순서를 각자 독립적으로 진행한다.
- 현재 문제에 등록된 실제 차이를 모두 찾으면 즉시 다음 문제로 이동한다.
- 제한시간이 끝나거나 양쪽이 전체 덱을 완주하면 경기가 종료된다.
- 정답 1개당 10점과 전체 완주 시 남은 시간 1초당 0.5점을 합산한다.
- 동점이면 오답이 적은 플레이어, 전체 덱을 먼저 완료한 플레이어 순으로 판정하고 나머지는 무승부다.
- 오답 입력 잠금은 난이도에 따라 0.5초·1초·2초다.

## 정리한 불일치

- 고정 `차이 3개`, 완료 이미지 수 우선, 오답 1초 고정 안내를 문제별 실제 수·점수·난이도 규칙으로 교체했다.
- 로비와 경기 중 오답 안내를 공유 설정 값에 맞게 갱신했다.
- 이미 제거된 구형 제작자/찾는 사람 편집기와 호환 코드의 백로그 상태를 완료로 정리했다.
- 에셋 계약은 한 곳 이상의 검수된 정답을 허용하되 현재 활성 5세트가 각각 3곳이라는 사실을 구분해 기록했다.

## 후속 과제
