## 승인 규칙

모든 `BLOCKER`가 `PASS` 또는 승인 근거가 있는 `NOT_APPLICABLE`이어야 검토 요청이 가능하다. 문서 작성, 로컬 테스트 또는 추정만으로 외부 증거를 PASS 처리하지 않는다.
