# 변경 요약 — 두 번째 연구실 장면 등록 (2026-07-31)

> 문서 상태: HISTORICAL
> 현재 에셋 조건은 `GAME_ASSETS.md`, 현재 규칙은 `GAME_RULES.md`를 따른다.

## 변경

- 사용자 제공 Nano Banana 연구실 PNG를 `cartoon-laboratory` 후보 장면으로 등록했다.
- 로봇 팔, 현미경, 플라스크, 시계, 식물, 시험관, 공구함 등 18개 객체 마스크를 추가했다.
- 공유 장면·객체 계약, 웹 카탈로그, 서버 원본 카탈로그와 객체 검증을 함께 연결했다.
- 서버가 두 후보 장면 중 하나를 선택하고 재접속·복구 시 같은 장면 ID를 유지한다.
- 내부 검수와 E2E에서 `GAME_SCENE_ID`로 특정 장면을 고정할 수 있다.
- 브라우저 E2E가 어느 장면을 받아도 장면별 객체 3개를 선택하도록 갱신했다.
- 연구실 18개 객체 마스크를 실제 PC·모바일 렌더링과 대조해 배경 침범을 줄였다.
- 모바일에서는 효과 마스크와 분리된 터치 여유 영역을 사용하며, 18개 객체 중심점 선택을 회귀 테스트로 고정했다.

## 남은 승인 조건

- 현재 원본은 1024×572이며 정확한 16:9가 아니다.
- 현재 후보 이미지의 PC·모바일 마스크 1차 육안 검수는 완료했다.
- 출시 전 1920×1080 정본과 서비스용 최적화 파일을 확보한 뒤 새 정본 기준으로 객체 경계를 다시 검수해야 한다.

## 후속 권리 확인

- 제작자인 사용자가 2026-07-31 대화에서 이미지의 상업적 사용·수정·배포를 포함한 프로젝트 사용을 허가했다.
- 이에 따라 `cartoon-laboratory`의 라이선스 상태를 `VERIFIED`로 변경했다.
- 남은 조건은 권리 문제가 아니라 정확한 16:9 정본, 서비스용 최적화 파일과 교체 후 마스크 재검수다.
