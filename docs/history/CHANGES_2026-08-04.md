# 2026-08-04 변경 기록

> 문서 상태: HISTORICAL — 동시 빨리찾기 전환 결정과 문서 정비 기록

## 결정

- 경기 중 제작자가 차이점을 만드는 비대칭 방식을 폐기하기로 했다.
- 두 플레이어가 같은 원본·변경본과 같은 문제 순서를 받아 동시에 찾는다.
- 차이 3개를 모두 찾은 플레이어는 상대를 기다리지 않고 다음 문제로 이동한다.
- 제한시간 동안 완료 문제 수, 현재 문제 발견 수, 오답이 적은 순서로 승패를 정한다.
- 문제별 선착 보너스와 온라인 경쟁전 힌트는 사용하지 않는다.
- 오답은 1초 입력 잠금으로 처리한다.

## 문서와 에셋

정본과 상태·기획·흐름·화면·기술·테스트·백로그·에셋 문서를 함께 정합화했다. 같은 변경에서 공유 타입·게임 코어·서버·웹·테스트를 전환하고 문서를 `CURRENT`로 승격했다. 과거 변경 기록은 당시 구현을 설명하므로 덮어쓰지 않는다.

숲과 바다 원본·변경본에 수동 정답 영역 3곳을 등록했다. 실제 플레이 난이도 검수는 남아 있다. 전체 캔버스의 생성형 미세 픽셀 변화 때문에 자동 픽셀 차이를 정답으로 사용할 수 없다. 카페·도시·연구실에는 유효한 변경본이 필요하다.

## 구현 영향

공유 상태·수치, 게임 코어, 서버 이벤트·저장, 웹 비교 화면과 자동 테스트를 새 규칙으로 전환했다. 구형 편집기 파일 정리와 추가 콘텐츠·모바일 확대는 후속 작업이다.
