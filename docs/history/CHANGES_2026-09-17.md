## 완료 범위

- Private R2의 `home-office` original/modified 두 객체만 제공하는 Cloudflare Worker를 구성했다.
- Worker는 정확한 두 경로의 GET/HEAD만 허용하며, 다른 경로와 변경 메서드는 R2 접근 전에 거부한다.
- `VITE_R2_CANARY_BASE_URL`이 유효한 origin일 때만 `home-office`를 Worker로 전환한다.
- Canary 설정이 없으면 모든 퍼즐이 기존 Git/Vite 이미지를 사용한다.
- 다른 경쟁 퍼즐, Solo, Pending 이미지와 서버·DB·게임 규칙은 변경하지 않았다.
- preload Promise 재사용, 실패 후 재시도, current/next의 R2·Git 혼합 preload를 검증했다.

- malformed URL, 외부 HTTP, credentials, path, query, hash가 포함된 Canary URL을 거부하도록 보강했다.

## 미완료 및 다음 단계

- 실제 게임 및 Apps in Toss WebView에서의 완전한 Canary E2E는 아직 완료로 판단하지 않는다.
- `VITE_*`는 빌드 시점 값이므로 활성화·비활성화 뒤 앱 재시작 또는 재빌드가 필요하다.
- 다음 검증에서는 Canary URL을 설정한 뒤 실제 게임에서 `home-office` 두 요청이 Worker로, 다른 퍼즐은 Git asset으로 가는지 확인한다.
- 수동 E2E가 끝나기 전에는 main 병합 또는 운영 활성화를 승인하지 않는다.
