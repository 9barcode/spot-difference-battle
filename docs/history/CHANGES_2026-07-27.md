# 변경 요약 — 다중 게임 장면 기반 (2026-07-27)

> 문서 상태: HISTORICAL
> 장면 카탈로그 기반을 추가한 변경 기록이다. 현재는 장면 1개와 단일 서버 원본 검증만 있으므로 다중 장면 출시 완료를 의미하지 않는다. 현재 조건은 `GAME_ASSETS.md`를 따른다.

## 핵심 변경

- 서버와 웹이 공유하는 게임 장면 ID 목록을 추가했다.
- 서버가 새 경기 생성 시 등록된 장면 중 하나를 선택하도록 변경했다.
- 선택된 장면 ID는 경기 스냅샷과 활성 경기 저장 데이터에 포함돼 재접속·서버 재시작 후에도 유지된다.
- 웹에 이미지, 대체 텍스트, 객체 마스크, 자동 보충 후보와 라이선스 상태를 묶는 장면 카탈로그를 추가했다.
- 편집기와 문제 이미지 합성이 전달받은 장면 정의를 사용하도록 하드코딩을 제거했다.
- 알 수 없는 이전 장면 ID는 기본 장면으로 안전하게 대체한다.

## 현재 범위

- 기존 거실 장면만 `prototype-room`으로 등록했다.
- 기존 에셋의 구체적인 라이선스 증빙이 없어 `UNVERIFIED` 상태로 기록했다.
- 최종 연구실 원본과 객체 마스크는 아직 포함하지 않았다.

## 검증 대상

- 장면 객체 ID 중복과 자동 보충 후보 유효성
- 서버 장면 선택과 저장·복구 후 장면 ID 유지
- 기존 싱글 플레이와 온라인 제작·풀이 흐름 회귀
- TypeScript 검사, 프로덕션 빌드, 단위·통합·브라우저 E2E
