# 테스트 계획

> 문서 상태: CURRENT
> 기준일: 2026-08-11
> 기대 동작은 `GAME_RULES.md`를 따른다. 코어·서버·웹·Chromium E2E는 새 동시 빨리찾기 흐름을 검증한다.

## 출시 전 필수 조건

- 두 플레이어가 동일한 문제 순서와 버전을 받는다.
- 이미지 로드 완료 후 같은 서버 시각에 시작한다.
- 각 플레이어가 독립적으로 문제를 완료하고 다음 문제로 이동한다.
- 차이 3개, 오답 1초 잠금과 서버 마감이 일치한다.
- 완료 문제 수, 현재 발견 수, 오답과 무승부 우선순위가 정확하다.
- 상대의 정답 위치와 이후 문제 정답이 종료 전에 노출되지 않는다.
- 데스크톱·모바일의 확대·정규화 좌표가 일치한다.
- 재접속, 이탈, 로드 실패와 서버 오류가 정의된 결과로 끝난다.
- 모든 문제 쌍의 이미지·정답·버전·라이선스를 재검토할 수 있다.

## 코어 단위 테스트

- `PRELOADING → COUNTDOWN → PLAYING → FINISHED` 전이
- 플레이어별 독립 문제 인덱스와 발견 집합
- 정답, 오답, 중복 정답 무페널티와 1초 입력 잠금
- 3개 완료 후 다음 문제 이동
- 완료 문제 수·현재 발견 수·오답 우선순위와 무승부
- 마감 이후·잠금 중·오래된 문제 입력 차단
- 직접 이탈·재접속 실패 기권과 신뢰 불가 취소
- 직렬화·복구 후 동일한 문제 순서와 진행 유지

## 서버 통합 테스트

- 양쪽에 같은 문제 순서 배정
- 준비와 동일한 문제 ID·에셋 버전 로드 승인 후 공통 시작 시각 배포
- 현재 문제의 서버 정답 영역 판정
- 조작된 `pairId`, 문제 인덱스, 버전과 좌표 차단
- 상대에게 정답 위치가 없는 스냅샷
- 한쪽의 다음 문제 이동이 상대 진행을 바꾸지 않음
- 동시 입력과 시간 종료의 결정적 결과
- 완료 경기의 문제 순서·버전·정답 영역과 양쪽 발견 수·오답 저장 및 신고 감사
- PostgreSQL 재시작 후 진행 복구

## 브라우저 E2E

- 두 브라우저 매칭·준비·사전 로드·카운트다운
- 양쪽에 같은 원본·변경본 표시
- 한 플레이어만 먼저 다음 문제로 이동
- 상대 진행 수치만 표시하고 정답 위치는 숨김
- 제한시간 결과 동기화
- 데스크톱·모바일 조합과 모바일 확대·이동
- 새로고침·재접속과 다중 탭
- Chromium·Firefox·WebKit

현재 390×844 모바일과 1280×900 데스크톱 조합에서 2배 확대, 드래그 무오답, 확대 후 정규화 정답 좌표를 Chromium·Firefox·WebKit으로 자동 검증한다.

실기 검수에서는 PC와 휴대폰을 같은 사설 Wi-Fi에 연결하고 `http://<PC IPv4>:5173`으로 접속한다. 휴대폰에서 로비 연결, 2인 매칭, 5문제 정답 판정, 확대·드래그, 오답 잠금, 다음 문제 전환과 결과 화면을 확인한다. 개발 CORS는 `localhost`, `127.0.0.1`, RFC 1918 사설 IPv4의 5173 포트만 허용해야 한다.

## 문제 에셋 검수

- 이미지 쌍의 크기, 비율, 크롭과 버전 일치
- 의도한 정답 영역 정확히 3개
- 영역 밖 생성형 미세 변화가 정답으로 등록되지 않음
- 모바일에서 각 차이를 독립적으로 식별 가능
- 텍스트·상표·워터마크·부적절한 표현 없음
- 라이선스와 생성 기록 확인
- 문제별 평균 풀이 시간과 오답률 수집

현재 카페·숲·바다·도시·겨울 5쌍은 자동 픽셀 비교가 아니라 제작자가 의도한 3곳의 수동 정답 영역으로 검증한다. 모든 배포 파생본은 1024×1024 WebP이며 무작위 문제 순서, 좌표 판정, 선로딩 캐시와 전체 덱 완주를 서버·브라우저 테스트에서 확인한다. 연구실은 유효한 변경본이 추가되기 전에는 문제 세트 테스트 대상이 아니다.

## 접근성·보안·운영

- 색상만으로 정답·오답·잠금을 구분하지 않는다.
- 키보드 포커스와 스크린리더 이름을 확인한다.
- 확대 동작이 정답 클릭으로 오인되지 않는지 확인한다.
- 과도한 선택 요청과 다른 경기 입력을 제한한다.
- 로그에 인증 정보와 정답 전체가 불필요하게 노출되지 않는다.
- 신고된 문제를 정확한 버전으로 재현할 수 있다.

## 결함 우선순위

- 치명적: 진행 불가, 잘못된 승패, 정답 노출, 양쪽 문제 순서 불일치
- 높음: 타이머·점수·복구·이미지 로드 공정성 오류
- 보통: 우회 가능한 화면·접근성·운영 문제
- 낮음: 결과에 영향 없는 표현과 시각 문제
