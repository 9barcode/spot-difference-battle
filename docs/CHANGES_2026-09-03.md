# 2026-09-03 객체 판정과 설정별 매칭 보강

> 문서 상태: HISTORICAL

## 문제

- 정답 하나를 원형 영역 하나로만 표현해, 중세 용처럼 길고 불규칙한 객체는 머리나 몸통 일부만 정답으로 인정됐다.
- 어려움은 판정 원을 80%로 줄이고 쉬움은 125%로 늘려, 이미지에서 실제로 바뀐 객체와 클릭 결과가 난이도에 따라 달라졌다.
- 서버는 같은 설정끼리 매칭했지만 로비 문구와 자동 검증만으로는 누가 난이도를 정하는지 명확하지 않았다.

## 변경

- 정답 하나가 하나 이상의 원형 영역을 갖도록 게임 코어 유효성 검사와 겹침 검사를 확장했다.
- 중세 용 색상 정답을 머리·몸통·날개·뒷몸·꼬리의 5개 영역으로 보정했다.
- 모든 난이도에서 검수된 객체 영역을 그대로 사용한다. 난이도 차이는 이미지 풀과 오답 잠금 0.5초·1초·2초로 유지한다.
- 로비에 양쪽이 직접 선택한 모드와 난이도가 모두 같을 때만 매칭된다고 표시했다.
- 서로 다른 모드 또는 난이도는 섞이지 않고 같은 설정의 상대와 각각 매칭되는 서버 통합 테스트를 추가했다.

## 검증

- `pnpm check`: 통과
- `pnpm test`: 82개 통과, PostgreSQL 실연동 2개는 테스트 DB 부재로 건너뜀
- `pnpm e2e`: Chromium·Firefox·WebKit 9개 통과
