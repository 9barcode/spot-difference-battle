# 변경 요약 — 객체 선택 레이어 수정 (2026-07-26)

## 문제

- 객체 편집 화면에서 카펫의 SVG 선택 영역이 고양이와 공보다 위에 렌더링됐다.
- 카펫 위에 놓인 공을 클릭하면 카펫 영역이 포인터 이벤트를 가로채 공을 선택할 수 없었다.
- 객체 3개 편집 E2E는 편집 완료 문구가 안내문과 제출 버튼에 동시에 존재해 strict locator 오류도 발생했다.

## 수정

- 카펫을 서랍장·고양이·공보다 먼저 렌더링해 배경 객체가 전경 객체의 클릭을 가리지 않도록 했다.
- E2E가 편집 완료 상태와 제출 동작을 `submit-problem` 테스트 ID로 명확하게 확인하도록 수정했다.
- 객체 좌표, 마스크, 제외 마스크와 게임 데이터는 변경하지 않았다.

## 검증

- `pnpm check`
- `pnpm build`
- `pnpm test` — 36개 통과
- `pnpm e2e` — Chromium·Firefox·WebKit에서 9개 통과
