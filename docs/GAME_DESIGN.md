# 게임 기획

> 문서 상태: CURRENT
> 기준일: 2026-08-25
> 규칙과 수치는 `GAME_RULES.md`를 따른다.

## 한 줄 설명

두 플레이어가 동일한 원본·변경본을 동시에 비교하고 문제마다 등록된 차이를 모두 찾으며, 정답 점수와 전체 덱 완주 시간 가산점을 겨루는 실시간 빨리찾기 대결이다.

## 핵심 재미

- 관찰력과 반응 속도를 직접 겨룬다.
- 문제를 완료할 때마다 흐름이 끊기지 않고 다음 장면으로 넘어간다.
- 상대의 진행도를 보며 추격하거나 격차를 벌린다.
- 짧고 명확한 경기 결과로 재도전을 유도한다.

## 핵심 루프

`매칭 → 준비·이미지 로드 → 3초 카운트다운 → 비교·발견 → 현재 문제의 모든 차이 완료 → 다음 이미지 → 첫 전체 완주 또는 시간 종료 → 결과`

두 플레이어는 같은 문제 순서를 사용하지만 진행은 독립적이다. 문제별 선착 보너스는 없고, 전체 덱을 빨리 완주하면 남은 시간에 비례한 가산점을 받는다.

## 플레이 경험

- 데스크톱: 원본과 변경본을 나란히 표시한다.
- 모바일: 원본·변경본을 상하 배치하고 1~3배 동기화 확대와 드래그 이동을 제공한다. 빠른 이미지 전환 방식은 후속 검토한다.
- 답은 변경본에서 선택한다.
- 자신의 발견 위치만 표시하고 상대 위치는 숨긴다.
- 상대의 현재 문제와 `찾은 수/실제 차이 수`는 실시간으로 표시한다.
- 오답은 난이도별 0.5~2초 입력 잠금으로 무작위 연타를 막는다.

## 콘텐츠 원칙

- 문제마다 검수된 차이를 한 곳 이상 등록한다. 현재 활성 5세트는 각각 3곳이다.
- 차이는 색상만으로 구분하지 않고 형태·존재·상태 변화를 섞는다.
- 정답 영역 밖의 생성형 미세 변화는 정답으로 쓰지 않는다.
- 문제별 난이도와 모바일 식별성을 검수한다.
- 같은 경기 안에서는 문제를 반복하지 않는다.

## 성공 지표

- 경기 완주율과 평균 완료 문제 수
- 문제별 평균 풀이 시간과 오답률
- 첫 경기 후 재대전 또는 새 매칭 진입률
- 모바일·데스크톱 간 정답률 차이
- 이미지 로드 실패율과 재접속 성공률
- 문제 신고율

## MVP 제외

랭킹, 시즌, 상점, 사용자 이미지 업로드, 채팅, 관전, 리플레이와 문제별 선착 보너스는 후속 검토한다.
