# 게임 기획

> 문서 상태: CURRENT
>
> 기준일: 2026-08-02
> 현재 구현된 비대칭 MVP를 요약하는 파생 문서다. 게임 규칙은 유일한 정본 `GAME_RULES.md`, 변경 근거는 `MVP_DECISIONS.md`를 따른다.

## 1. 게임 개요

한 플레이어가 원본 장면의 객체 3개를 수정해 문제를 만들고, 다른 플레이어가 제한시간 안에 그 차이를 빠르게 찾는 실시간 1대1 비대칭 공방 게임이다. 두 플레이어가 동시에 같은 문제를 찾아 속도를 비교하지 않는다. 먼저 매칭된 플레이어가 제작자, 두 번째 플레이어가 찾는 사람이 된다.

같은 제작·풀이 흐름을 혼자 확인하는 1인 테스트 모드도 제공한다. 1인 모드는 클라이언트 테스트 기능이며 온라인 전적에 포함하지 않는다.

## 2. 핵심 목표

- 짧은 시간 안에 한 판을 완주할 수 있다.
- 제작자는 이해하기 쉬운 객체 단위 편집으로 문제를 만든다.
- 찾는 사람은 제작 과정과 정답 정보를 미리 받지 않는다.
- 서버가 역할, 시간, 정답, 오답과 승패를 최종 판정한다.
- 데스크톱과 모바일에서 같은 좌표가 같은 답으로 처리된다.

## 3. 한 판의 흐름

1. 닉네임을 설정하고 빠른 대전을 시작한다.
2. 두 플레이어가 매칭되고 각자의 역할을 확인한다.
3. 양쪽이 준비를 완료한다.
4. 제작자가 객체 3개를 수정한다. 찾는 사람은 비공개 대기 화면을 본다.
5. 제작자가 수정 완료를 누르면 합성된 문제 이미지가 서버로 제출된다.
6. 찾는 사람에게 원본과 문제 이미지를 제공하고 풀이를 시작한다.
7. 찾는 사람이 차이 3개를 모두 찾거나 제한시간이 끝나면 서버가 결과를 확정한다.
8. 결과와 전체 정답을 확인한 뒤 로비로 돌아가거나 문제를 신고한다.

재대전과 결과 화면의 즉시 새 매칭은 현재 제공하지 않으며 후속 기능으로 관리한다.

## 4. 역할

### 제작자

- 준비된 장면의 고정 객체 중 서로 다른 3개를 선택한다.
- 색상, 가로 확대, 세로 확대, 줄무늬, 점무늬, 별 무늬, 윤곽 효과를 적용할 수 있다.
- 수정 결과를 클라이언트에서 PNG 문제 이미지로 합성해 제출한다.
- 찾기 단계에는 참여하지 않고 상대 진행도를 확인한다.

### 찾는 사람

- 제작 중에는 원본, 수정본, 선택 객체와 정답 위치를 받지 않는다.
- 풀이 단계에서 원본과 완성된 문제 이미지를 비교한다.
- 수정 이미지에서만 답을 선택하고 경기당 힌트 1회를 사용할 수 있다.

## 5. MVP 범위

### 포함

- 게스트 닉네임
- 무작위 1대1 빠른 대전
- 제작자·찾는 사람 역할 분리
- 객체 3개 기반 문제 제작
- 서버 권한 타이머와 판정
- 오답 페널티와 힌트
- 10초 재접속 유예와 기권
- 결과·전체 정답 공개·신고
- 1인 테스트 모드
- 데스크톱·모바일 웹
- PostgreSQL 선택 사용과 메모리 저장소 대체

### 미완료 또는 출시 전 필요

- 라이선스가 확인된 장면 10개
- 완료된 문제 이미지·정답 정보의 운영 감사용 보관
- 운영 지표·로그·모니터링
- 스테이징 배포와 롤백

### 보류

- 재대전과 결과 화면 즉시 새 매칭
- 계정, 랭킹, 시즌, 상점, 결제
- 친구 대전, 초대, 채팅, 관전, 리플레이
- 사용자 이미지 업로드

## 6. 콘텐츠 방향

현재 장면 6개가 등록돼 있다. 연구실과 사용자 제작 카페·숲·도시·바다 장면은 `VERIFIED`, 거실은 `UNVERIFIED`다. 연구실은 1920×1080 PNG와 무손실 WebP·AVIF가 준비됐으며 새 4개 장면은 1024×1024 플레이 검증용이다. 다중 장면 카탈로그와 무작위 선택은 동작하지만 새 장면의 16:9 출시 정본과 최종 마스크 육안 검수가 남아 있다. 출시 콘텐츠 기준과 등록 절차는 `GAME_ASSETS.md`를 따른다.

## 7. 성공 지표

- 매칭 성공률과 경기 완주율
- 제작 시간 및 자동 보충 비율
- 찾기 완료율, 평균 오답 수, 힌트 사용률
- 연결 끊김과 복구·기권 비율
- 취소 및 신고 비율
- 한 판 후 다시 매칭하려는 의향
