# 게임 기획서

## 1. 게임 개요

Spot Difference Battle은 두 플레이어가 같은 그림에 직접 차이점을 만든 뒤, 상대가 만든 문제를 실시간으로 푸는 1대1 경쟁 게임이다. 일반적인 틀린그림찾기의 관찰 재미에 문제를 직접 만드는 창작과 심리전 요소를 더한다.

## 2. 목표 사용자

- 짧고 직관적인 대전을 선호하는 캐주얼 게임 사용자
- 친구와 가볍게 경쟁하거나 결과를 공유하고 싶은 사용자
- 복잡한 조작보다 관찰력과 센스를 겨루고 싶은 사용자

## 3. 핵심 재미

- **발견:** 제한시간 안에 미묘한 차이를 찾아내는 긴장감
- **창작:** 상대가 헷갈릴 만한 차이를 직접 만드는 재미
- **심리전:** 어렵지만 공정한 위치와 표현을 선택하는 전략
- **즉시 경쟁:** 상대의 진행도가 실시간으로 보이는 압박감

## 4. 핵심 게임 루프

1. 매칭한다.
2. 동일한 원본 그림을 확인한다.
3. 각자 차이점 3개를 만든다.
4. 서로의 문제를 교환한다.
5. 제한시간 동안 상대의 차이점을 찾는다.
6. 결과를 확인하고 재대전하거나 새 상대를 찾는다.

한 판은 매칭 시간을 제외하고 약 2분 안에 끝나는 것을 목표로 한다.

## 5. 플레이 단계

### 매칭

두 플레이어를 한 경기에 연결하고 같은 원본 이미지를 배정한다. 양쪽이 준비되어야 제작 단계로 이동한다.

### 차이점 제작

플레이어는 스티커 추가, 일부 가리기, 색상 변경 중 제공된 도구를 사용해 차이점 3개를 만든다. 시스템은 크기, 간격, 화면 경계 등 기본 공정성 조건을 검사한다.

### 문제 교환

양쪽 제출이 완료되면 각 플레이어에게 원본과 상대가 수정한 이미지를 제공한다. 제작 결과는 풀이 시작 전까지 상대에게 공개하지 않는다.

### 차이점 찾기

플레이어는 수정된 이미지에서 차이가 있다고 판단한 위치를 선택한다. 서버는 정답 여부와 완료 순서를 판정한다. 상대가 찾은 개수는 공개하되 위치는 공개하지 않는다.

### 결과

승패와 판정 근거, 놓친 차이점, 오답, 힌트 사용 여부를 보여준다. 재대전, 새 매칭, 로비 이동, 문제 신고를 제공한다.

## 6. MVP 범위

### 포함

- 웹 기반 실시간 1대1 매칭
- 준비된 원본 이미지 풀
- 차이점 3개 제작 및 제출
- 제작 도구 3종: 추가, 가리기, 색상 변경
- 정답·오답 판정과 타이머
- 힌트 1회
- 결과 및 재대전 흐름
- 이탈, 연결 끊김, 서버 오류에 대한 기본 처리

### 제외

- 랭크, 시즌, 리더보드
- 재화, 상점, 유료 힌트
- 사용자 이미지 업로드
- 관전 및 리플레이
- 다인전과 토너먼트
- 친구·길드·채팅 시스템
- 정교한 자동 부정행위 탐지

## 7. 제품 원칙

- 규칙은 첫 판에도 설명 없이 이해할 수 있어야 한다.
- 어려운 문제와 불공정한 문제를 구분한다.
- 승패와 시간 판정은 클라이언트가 아닌 서버 기록을 기준으로 한다.
- 상대의 진행 상황은 긴장감을 주되 정답 정보는 노출하지 않는다.
- 연결 문제 때문에 사용자가 불합리한 패배를 경험하지 않도록 한다.

## 8. 초기 검증 지표

- 제작 단계 완료율
- 제작에 걸린 평균 시간
- 경기 완주율
- 차이점별 발견률과 평균 발견 시간
- 오답 및 힌트 사용 빈도
- 재대전 또는 새 매칭 선택률
- 불공정 문제 신고율
- 플레이 후 체감 공정성과 재플레이 의향

## 9. 미정 사항

- 비회원 닉네임만 사용할지 계정을 도입할지
- 원본 이미지 선정 및 교체 주기
- 제작 미완료 시 자동 생성의 품질과 적용 조건
- 재접속을 MVP부터 지원할지 여부
- 신고 누적에 따른 제재 기준
