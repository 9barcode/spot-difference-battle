# 변경 요약 — 데이터베이스 마이그레이션 보완 (2026-07-23)

> 문서 상태: HISTORICAL
> 현재 데이터베이스 실행 방법은 루트 `README.md`, 현재 저장 구조는 `TECH_SPEC.md`를 따른다.

## 변경 내용

- 실행 중인 매치 복구용 `active_matches` 테이블을 별도 `002_active_matches.sql` 마이그레이션으로 분리했다.
- 서버의 마이그레이션 명령이 `migrations` 폴더의 모든 SQL 파일을 파일명 순서대로 실행하도록 변경했다.
- 각 마이그레이션을 개별 트랜잭션으로 실행해 실패한 파일의 변경만 롤백하도록 했다.
- PostgreSQL 포트를 `127.0.0.1`에만 노출하고, 기존 훼손 흔적이 있는 볼륨과 분리된 새 개발 볼륨을 사용하도록 했다.
- 기본 개발용 PostgreSQL 비밀번호를 변경하고 `.env.example`과 일치시켰다.

## 변경 이유

기존 방식은 `001_initial.sql` 하나만 직접 실행하므로 후속 스키마 변경을 별도 파일로 추가해도 적용되지 않았다.
이제 번호가 붙은 SQL 파일을 추가하는 방식으로 기존 데이터베이스에도 순차적으로 스키마를 확장할 수 있다.

또한 기존 Docker 볼륨에서 정상 게임 DB 대신 `readme_to_recover` 데이터베이스가 발견됐다. 기존 볼륨은
증거와 복구 가능성을 위해 삭제하지 않고 보존했으며, 로컬 전용 포트와 새 볼륨으로 개발 DB를 격리했다.

## 실행 방법

```powershell
$env:DATABASE_URL="postgresql://postgres:spot-battle-local-only@127.0.0.1:5432/spot_difference_battle"
pnpm --filter @spot-battle/server db:migrate
```
