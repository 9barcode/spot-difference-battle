## 작업 원칙

- 현재 게임은 제작자 1명·찾는 사람 1명의 비대칭 구조다.
- `GAME_RULES.md`와 실제 `GameMatch`가 다르면 완료로 보지 않는다.
- 브라우저·통합·단위 테스트 범위를 서로 구분한다.
- 목표 설계는 현재 구현처럼 표현하지 않는다.
