> 기준일: 2026-08-27
> 체크는 새 규칙 구현과 자동 검증이 모두 있을 때만 사용한다.

- [x] 새 게임 규칙과 문서 영향 범위 확정

- [x] `PRELOADING`·`COUNTDOWN`·`PLAYING` 상태 추가
