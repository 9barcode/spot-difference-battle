# MVP 구현 백로그

## 작업 원칙

- 각 단계는 독립적으로 실행하고 검증할 수 있어야 한다.
- 서버 판정 없이 클라이언트만 성공한 상태를 완성으로 보지 않는다.
- 우선순위는 핵심 경기 완주, 공정한 판정, 오류 복구, 시각 개선 순이다.

## P0 — 프로젝트 토대

- [x] pnpm workspace를 웹, 서버, 공유 타입 패키지 구조로 정리
- [x] TypeScript 검사, 단위 테스트, 빌드 명령 통일
- [x] 환경 변수 예시와 로컬 실행 절차 문서화
- [x] PostgreSQL 로컬 개발 환경과 마이그레이션 구성
- [x] 경기·사용자·신고의 최소 데이터 모델 정의

**완료 조건:** 새 환경에서 한 명령 흐름으로 웹과 서버를 실행하고 검사할 수 있다.

## P0 — 핵심 도메인

- [x] `GAME_STATE.md` 기반 상태 전이 모델 구현
- [x] 정규화 좌표와 정답 영역 모델 구현
- [x] 차이점 개수·크기·간격·경계 검증
- [x] 정답·오답·동점 판정 구현
- [x] 서버 마감 시각과 중복 제출·정답 방지 구현
- [x] 현재 구현된 도메인 규칙 단위 테스트 작성

**완료 조건:** UI나 네트워크 없이도 모든 승패 및 예외 판정을 자동 테스트로 검증한다.

## P0 — 최소 웹 흐름

- [x] 활성 MVP 화면의 차이점 수를 3개로 통일
- [x] 닉네임 입력, 로비, 매칭, 제작, 교환, 풀이, 결과 화면 연결
- [x] 랭킹·상점·시즌·재화·친구 등 MVP 제외 UI 숨김
- [ ] 제작 제출 대기, 자동 보충, 오류 상태 추가
- [x] 재접속 오버레이와 상대 복귀 대기 상태 추가
- [ ] 서버 오류에 따른 경기 취소 결과 추가
- [x] 모바일 레이아웃과 포인터 좌표 처리

**완료 조건:** 실제 서버 상태로 정상·시간 초과·오류 흐름을 모든 대상 화면 크기에서 완주한다.

## P0 — 실시간 1대1 경기

- [x] 게스트 세션 발급과 닉네임 검증
- [x] 빠른 대전 매칭 큐
- [x] Socket.IO 연결과 경기 참가 권한 확인
- [x] 제작 제출과 서버 검증
- [x] 문제 교환과 동시 풀이 시작
- [x] 위치 선택, 힌트, 상대 진행도 이벤트
- [x] 서버 결과 확정과 양쪽 결과 동기화

**완료 조건:** 서로 다른 두 브라우저가 서버를 통해 한 판을 완주하고 같은 결과를 받는다.

## P0 — 복구와 공정성

- [x] 새로고침 및 연결 상실 후 10초 안 재접속
- [x] 영속 저장소 사용 시 서버 재시작 후 게스트 세션과 진행 중 경기 복구
- [x] 유예시간 초과와 직접 나가기 기권 처리
- [x] 치명적인 경기 처리 오류 시 승패 없는 취소 처리
- [x] 입력 빈도 제한과 상태 버전 검증
- [x] 정답 좌표 대신 합성 문제 이미지만 풀이 클라이언트에 전달

**완료 조건:** 네트워크 테스트 시나리오에서 잘못된 승패나 멈춘 경기가 없다.

## P1 — 콘텐츠와 운영

- [ ] 라이선스가 확인된 원본 이미지 10장 준비
- [ ] 이미지별 자동 보충 후보와 허용 영역 등록
- [x] 신고 저장과 중복 신고 방지 구성
- [x] 경기 상태, 취소, 연결 실패 지표 기록
- [x] 개인정보 없는 오류 로그와 기본 모니터링

**완료 조건:** 플레이테스트에서 사용한 경기와 신고 원인을 추적할 수 있다.

## P1 — 품질과 배포

- [ ] 핵심 도메인 단위 테스트
- [ ] 두 플레이어 E2E 테스트
- [ ] 모바일·데스크톱 좌표 정확도 테스트
- [x] 지연 입력과 재접속 테스트
- [x] 중복 이벤트, 오래된 상태, 입력 빈도 제한 테스트
- [x] PostgreSQL 기반 서버 재시작과 활성 경기 복구 테스트
- [ ] 접근성 및 지원 브라우저 점검
- [ ] 스테이징 배포와 롤백 절차 확인

**완료 조건:** `TEST_PLAN.md`의 출시 전 필수 조건을 모두 통과한다.

## 첫 번째 구현 마일스톤

아래 한 문장을 만족하면 첫 번째 세로형 프로토타입이 완료된다.

> 두 브라우저가 게스트로 연결되어 차이점 3개를 만들고 교환해 찾은 뒤, 서버가 확정한 동일한 결과를 확인한다.

이 마일스톤 전에는 랭킹, 상점, 시즌, 친구 기능을 구현하지 않는다.
