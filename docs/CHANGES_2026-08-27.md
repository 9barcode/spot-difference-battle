# 2026-08-27 변경 요약

> 문서 상태: HISTORICAL

## 첫 완주자 즉시 승리

- 기존에는 한 플레이어가 전체 문제를 완주해도 상대가 완주하거나 제한시간이 끝날 때까지 `PLAYING`을 유지했다.
- 이제 첫 플레이어가 마지막 문제의 마지막 정답을 맞히는 순간 서버가 해당 플레이어를 승자로 확정하고 즉시 `FINISHED`로 전환한다.
- 상대 클라이언트도 같은 서버 결과를 받아 즉시 패배 화면과 `한 플레이어 전체 문제 완료` 종료 사유를 표시한다.
- 제한시간이 먼저 끝난 경기에는 기존 총점·오답 순서 판정을 유지한다.

## 동기화 범위

- 게임 코어 종료 조건과 승자 확정
- 서버 소켓 통합 테스트
- Chromium·Firefox·WebKit 2인 E2E
- 로비·완주 대기 방어 화면·결과 종료 사유 문구
- `GAME_RULES.md`, 상태·흐름·기획·테스트·백로그와 릴리스 기록

## 신규 EASY 문제 5쌍

- 사용자 제공 우주정거장·하와이 해변·연금술 작업실·공룡 계곡·해적선 원본/변경본을 올바른 파일명 쌍으로 연결했다.
- 각 쌍의 의도한 차이 3곳을 픽셀 분석과 육안 검토로 확인하고 서버 정규화 정답 영역으로 등록했다.
- 제공 JPG는 원본 해시 기록으로 남기고 배포본은 1024×1024 WebP 품질 88로 최적화했다.
- 공유 매니페스트·서버 카탈로그·웹 카탈로그·E2E를 총 10문제 기준으로 동기화했다.
- 최초 등록 시 신규 5쌍을 `EASY`로 기록했으며, 기존 5쌍의 파일명 난이도 재분류는 아래 보정 단계에서 처리했다.
- PostgreSQL 재시작 테스트의 저장 스키마 기대값을 현재 `schemaVersion: 4`에 맞췄다.

## 난이도 파일명 분류 보정

- `easy_bakery`, `medium_mushroom`, `hard_cyberpunk` 쌍을 각각 EASY·MEDIUM·HARD 문제의 최신 버전으로 교체했다.
- 세 쌍의 실제 차이에 맞춰 시계·꽃·고양이, 등불·목도리·새, 네온·비행 자동차·헤드폰 정답 영역을 다시 등록했다.
- 서버가 선택 난이도의 등급 문제와 `UNRATED` 공용 문제만 섞도록 변경했다.
- E2E는 고정 10문제가 아니라 서버가 배정한 난이도별 전체 덱 수를 읽어 완주를 검증한다.

## EASY·MEDIUM 문제 6쌍 추가

- `easy` 폴더의 일본 신사·한국 궁궐·중세 성 3쌍을 EASY로 등록하고 의도한 차이 3곳씩 판정 영역으로 연결했다.
- `medium` 폴더의 일본 닌자·한국 도깨비·중세 용 3쌍을 MEDIUM으로 등록하고 의도한 차이 5곳씩 판정 영역으로 연결했다.
- 활성 문제는 16세트이며 공용 문제를 포함한 실제 풀은 EASY 11문제, NORMAL(MEDIUM) 6문제, HARD 3문제다.
- 모든 완전한 쌍을 품질 88 WebP로 변환하고 원본·배포본 SHA-256을 기록했다.
- `hard/medieval_alchemist_original.jpg`는 변경본이 없어 활성화하지 않았다.
