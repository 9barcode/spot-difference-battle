# 게임 문제 에셋 가이드

> 문서 상태: CURRENT
> 기준일: 2026-08-27

## 1. 에셋 모델

게임 콘텐츠 단위는 단일 장면이 아니라 `원본 + 변경본 + 검수된 정답 영역`으로 구성된 문제 쌍이다. 경기 중 플레이어가 이미지를 수정하지 않는다.

활성 문제의 실행 기준은 `packages/shared/src/puzzle-asset-manifest.ts` 한 곳이다. 이 매니페스트가 문제 ID, 버전, 난이도 상태, 권리 상태, 원본·변경본 파일명, 크기와 SHA-256을 공유하며 웹·서버 테스트가 실제 파일 및 카탈로그와의 일치를 검사한다. 이미지 파일을 교체할 때는 같은 이름으로 덮어쓰지 말고 버전과 해시를 함께 올려야 한다.

파일명과 제공 폴더에 명시된 난이도를 기준으로 `easy_bakery`, `easy1`~`easy5`, 일본 신사·한국 궁궐·중세 성은 `EASY`, `medium_mushroom`, 일본 닌자·한국 도깨비·중세 용은 `MEDIUM`, `hard_cyberpunk`는 `HARD`로 기록한다. 바닷속 보물과 겨울 산장은 플레이 데이터가 없어 `UNRATED`이며 모든 난이도의 공용 풀에서 사용한다. 모든 활성 문제의 권리 상태는 사용자가 직접 제작·제공했음을 뜻하는 `USER_SUPPLIED`다. `USER_SUPPLIED`는 제공 경로 기록이지 제3자 법률 검증을 뜻하지 않는다.

문제마다 다음을 준비한다.

- 고유 `pairId`와 버전
- 원본 PNG와 서비스용 WebP 또는 AVIF
- 변경본 PNG와 서비스용 WebP 또는 AVIF
- 한 곳 이상의 정답 ID·이름·정규화 영역과 실제 정답 수
- 이미지 크기·해시와 난이도
- 원작자, 생성 도구, 생성일, 이용 조건과 원본 증빙
- 모바일 육안 검수 결과와 활성 상태

이전 카페·도시 동일 파일과 추가 차이가 있던 숲 파일은 역사 자산으로만 보존한다. 2026-08-09에 제공된 새 5쌍은 각 쌍의 의도한 차이 3곳을 수동 정답 영역으로 등록했다. 제공 JPG의 SHA-256은 권리 기록에 보존하고, 웹 배포에는 동일한 1024×1024 크기의 WebP 품질 88 파생본을 사용한다.

현재 온라인 테스트에는 총 16세트가 등록돼 있다. 매칭 난이도별 풀은 `EASY 9 + UNRATED 2 = 11세트`, `MEDIUM 4 + UNRATED 2 = 6세트`, `HARD 1 + UNRATED 2 = 3세트`다. 한 경기 안에서는 같은 문제가 반복되지 않는다. HARD의 중세 연금술사는 변경본이 없어 활성 풀에서 제외했다.

32개 배포 이미지의 합계는 제공 JPG 32,278,966바이트에서 WebP 9,050,286바이트로 줄었다. 모든 파일은 1024×1024 RGB로 디코딩되며 매니페스트 테스트가 배포 파일 SHA-256을 확인한다.

## 3. 이미지 조건

- 원본과 변경본의 크기·비율·구도·크롭이 같음
- 제목, A/B 표시, 테두리, 상표와 워터마크 없음
- 의도한 차이를 모두 등록하며 현재 활성 EASY 문제는 3곳, 신규 MEDIUM 문제는 5곳
- 영역 밖 화풍·조명·노이즈 변화 최소화
- 모바일에서 확대했을 때 독립적으로 식별 가능한 크기
- 색상만 구별해야 하는 문제에 의존하지 않음
- 정답 영역이 겹치지 않고 화면 가장자리에서 잘리지 않음

첫 출시 문제는 원본과 변경본 모두 같은 1024×1024 정사각형이어야 한다. 비정사각 이미지는 실제 `object-fit` 표시 영역에 맞춘 좌표 변환을 구현하고 자동 검증하기 전까지 등록하지 않는다.

## 4. 등록 절차

1. 출처와 이용 조건을 확인한다.
2. 원본·변경본에 안정적인 ID와 버전을 부여한다.
3. 두 이미지의 크기·크롭과 해시를 확인한다.
4. 제작자가 의도한 모든 차이를 이름과 정규화 영역으로 등록한다.
5. PC·모바일에서 정답과 오답 경계를 육안 검수한다.
6. 서버 문제 카탈로그와 웹 자산 카탈로그를 함께 등록한다.
7. 단위·서버·브라우저 테스트를 실행한다.
8. 플레이 데이터로 난이도와 오답률을 확인한 뒤 활성화한다.

파일 순서나 업로드 순서로 original/modified를 추측하지 않는다. 카탈로그의 명시적 `originalImage`와 `modifiedImage` 필드를 사용한다.

## 5. 수량 목표

- 기능 개발과 내부 테스트: 검증된 5세트 이상
- 3분 경기: 각 난이도에서 같은 경기 중 반복되지 않는 10세트 이상
- 초기 반복 서비스: 난이도를 섞은 20~30세트 이상

## 6. 완료 조건

- 양쪽이 같은 문제 순서와 파일 버전을 사용한다.
- 현재·다음 문제를 경기 시간 손실 없이 불러온다.
- 등록된 실제 정답 수와 판정 영역이 일치하며 영역 밖 미세 변화는 판정하지 않는다.
- 모바일·데스크톱에서 같은 정규화 좌표가 같은 답이다.
- 라이선스가 확인되고 문제 버전을 재현할 수 있다.
- 신고 조사 기간 동안 이미지·정답·경기 사용 버전을 보존한다.
