# 게임 문제 에셋 가이드

> 문서 상태: CURRENT
> 기준일: 2026-08-31
> 책임 역할: 콘텐츠 책임자

## 1. 에셋 모델과 정본

게임 콘텐츠 단위는 단일 장면이 아니라 `원본 + 변경본 + 검수된 정답 영역`으로 구성된 문제 쌍이다. 경기 중 플레이어가 이미지를 수정하지 않는다.

활성 파일 메타데이터의 실행 기준은 `packages/shared/src/puzzle-asset-manifest.ts`다. 이 매니페스트가 문제 ID, 버전, 난이도, 권리 상태, 원본·변경본 파일명, 크기와 SHA-256을 공유하며 웹·서버 테스트가 실제 파일 및 카탈로그와의 일치를 검사한다.

서버 정답 영역은 `apps/server/src/game-puzzles.ts`, 웹 자산 연결은 `UI/src/app/game-puzzles.ts`에서 관리한다. 이미지 파일을 같은 이름으로 덮어쓰지 않고 버전과 해시를 함께 올린다.

문제마다 다음을 준비한다.

- 고유 `pairId`와 버전
- 원본과 변경본의 서비스용 WebP 또는 AVIF
- 한 곳 이상의 정답 ID·이름·정규화 영역
- 이미지 크기·SHA-256, 난이도와 활성 상태
- 원작자·제공자, 생성·편집 도구, 생성일, 이용 조건과 원본 증빙
- PC·모바일 육안 검수와 승인 기록

## 2. 난이도와 권리 상태

- `EASY`: 카페, 우주, 하와이, 연금술 작업실, 공룡, 해적, 일본 신사, 한국 궁궐, 중세 성
- `MEDIUM`: 마법의 버섯 숲, 일본 닌자, 한국 도깨비, 중세 용
- `HARD`: 네온 사이버 도시
- `UNRATED`: 바닷속 보물, 겨울 산장

`NORMAL` 경기는 `MEDIUM`, 모든 난이도는 `UNRATED` 공용 문제를 포함한다.

권리 상태 의미:

- `USER_SUPPLIED`: 사용자가 제공했다는 출처 기록. 상업 이용·재배포 법률 검증 완료를 뜻하지 않는다.
- `VERIFIED`: 지정된 권리 책임자가 증빙과 이용 조건을 검토·승인했다.
- `RESTRICTED`: 이용 조건이 불명확하거나 공개 서비스에 사용할 수 없다.

AI나 개발자가 증빙 없이 `VERIFIED`로 승격할 수 없다. 공개 출시에는 문제별 `templates/PUZZLE_QA.md`와 권리 승인자가 필요하다.

현재 활성은 16세트다. 난이도별 경기 풀은 `EASY 9 + UNRATED 2 = 11`, `MEDIUM 4 + UNRATED 2 = 6`, `HARD 1 + UNRATED 2 = 3`이다. 한 경기 안에서는 같은 문제를 반복하지 않는다.

32개 배포 이미지는 1024×1024 RGB WebP이며 합계 9,050,286바이트다. 매니페스트 테스트가 배포 파일 SHA-256을 확인한다.

## 4. 이미지·정답 조건

- 원본과 변경본의 크기·비율·구도·크롭 일치
- 제목, A/B 표시, 테두리, 상표와 워터마크 없음
- 의도한 모든 차이를 등록하고 실제 정답 수와 일치
- 영역 밖 화풍·조명·노이즈 변화 최소화
- 모바일 확대에서 독립적으로 식별 가능한 크기
- 색상만 구별해야 하는 문제에 의존하지 않음
- 정답 영역이 겹치지 않고 화면 가장자리에서 잘리지 않음
- 부적절한 표현, 문화적·연령 적합성 문제 없음

첫 출시 문제는 원본과 변경본 모두 같은 1024×1024 정사각형이어야 한다. 비정사각 이미지는 실제 `object-fit` 표시 영역의 좌표 변환을 자동 검증하기 전까지 등록하지 않는다.

## 5. 등록 절차

1. 출처, 생성 과정과 이용·재배포 조건을 확인한다.
2. 원본·변경본에 안정적인 ID와 버전을 부여한다.
3. 두 이미지의 크기·크롭과 SHA-256을 확인한다.
4. 제작자가 의도한 모든 차이를 이름과 정규화 영역으로 등록한다.
5. 공유 매니페스트, 서버 정답과 웹 자산을 함께 등록한다.
6. 파일·좌표·카탈로그 자동 테스트를 실행한다.
7. `templates/PUZZLE_QA.md`로 PC·모바일, 오답 경계와 표현을 육안 검수한다.
8. 권리 책임자가 증빙과 공개 사용을 승인한다.
9. 스테이징 플레이 데이터로 난이도와 오답률을 확인한 뒤 활성화한다.

파일 순서나 업로드 순서로 original/modified를 추측하지 않는다. 카탈로그의 명시적 필드를 사용한다.

## 6. 수량·출시 기준

- 기능 개발과 내부 테스트: 검증된 5세트 이상
- 공개 난이도: 같은 경기에서 반복되지 않는 10세트 이상 권고
- 초기 반복 서비스: 전체 20~30세트 이상 목표

현재 EASY만 10세트 기준을 충족한다. NORMAL·HARD 공개 범위와 정확한 덱 크기는 `REVIEW_REQUIRED.md`의 `REV-004`, `REV-005`에서 확정한다.

## 7. 완료 조건

- 양쪽이 같은 문제 순서와 파일 버전을 사용한다.
- 현재·다음 문제를 경기 시간 손실 없이 불러온다.
- 등록된 실제 정답 수와 판정 영역이 일치한다.
- 모바일·데스크톱에서 같은 정규화 좌표가 같은 답이다.
- 문제별 권리와 육안 QA가 승인됐다.
- 신고 조사 기간 동안 이미지·정답·경기 사용 버전을 보존한다.
- 문제별 풀이 시간·오답률·신고율로 재검토할 수 있다.
