# 2026-08-03 변경 내역

> 문서 상태: HISTORICAL

## 스테이징 배포 준비

- 프로덕션 웹이 별도 서버 주소 없이 현재 도메인의 Socket.IO에 연결하도록 변경했다.
- Fastify가 빌드된 React 정적 파일과 `/health`를 같은 서비스에서 제공할 수 있게 했다.
- Node 22·pnpm 11.9.0 기반 다단계 `Dockerfile`과 최소 빌드 컨텍스트를 위한 `.dockerignore`를 추가했다.
- Render 무료 웹 서비스와 무료 PostgreSQL을 Singapore 리전에 생성하는 `render.yaml`을 추가했다.
- `DATABASE_URL`이 있으면 컨테이너 시작 전에 기존 마이그레이션을 적용한다.
- 서버 검증용 PNG 6개를 운영 이미지에 포함하고 `GAME_ASSET_ROOT`로 monorepo 외부 런타임에서도 조회한다.
- 정적 웹과 상태 확인 경로가 함께 동작하는 서버 통합 테스트를 추가했다.
- 배포·환경변수·무료 환경 제한·모바일 확인·롤백 절차를 `DEPLOYMENT.md`에 정리했다.

- `pnpm test` 47개 통과, 실제 PostgreSQL 전용 1개 건너뜀
