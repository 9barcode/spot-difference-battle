# 변경 요약 — 1인 테스트와 객체별 비공개 제작 (2026-07-25)

## 핵심 변경

- 로비에 `1인 테스트 모드`를 추가했다.
- 1인 모드에서는 객체 3개를 수정하고 `수정 완료`를 누른 뒤 편집 화면을 숨긴 상태에서 직접 문제를 풀 수 있다.
- 온라인 경기를 문제 제작자 1명과 찾는 사람 1명의 비대칭 흐름으로 변경했다.
- 먼저 매칭된 플레이어가 제작자, 두 번째 플레이어가 찾는 사람이 된다.
- 제작 중에는 찾는 사람에게 원본·수정본·선택 객체·정답 좌표를 표시하지 않는다.
- 제작자가 `수정 완료`를 누르면 서버가 찾기 단계로 전환하고, 합성된 문제 이미지 한 장만 찾는 사람에게 전달한다.
- 찾는 사람만 정답 선택과 힌트 사용이 가능하다.
- 찾는 사람이 제한시간 안에 모두 찾으면 찾는 사람이 승리하고, 시간초과 시 제작자가 승리한다.

## 객체 편집 변경

기존의 픽셀 색상 유사도 기반 범위 선택을 제거하고 원본 장면에 수동 객체 맵을 정의했다.

분리된 객체는 다음과 같다.

- 화분과 식물
- 전등
- 소파
- 베개
- 창문
- 왼쪽·오른쪽 커튼
- 구름
- 시계
- 액자
- 꽃병
- 책
- 서랍장
- 고양이
- 공
- 카펫

각 객체는 독립 SVG 클릭 영역과 Canvas 마스크를 사용한다. 큰 객체 안에 포함된 작은 객체는 제외 마스크로 분리해, 예를 들어 소파를 바꿀 때 베개가 함께 선택되거나 카펫을 바꿀 때 고양이와 공이 같이 바뀌지 않도록 했다.

지원 효과:

- 색상만 변경
- 가로로 넓게
- 세로로 길게
- 줄무늬
- 점무늬
- 별 무늬
- 윤곽 변경

서로 떨어진 마스크 조각 사이가 Canvas 경로로 연결되어 넓은 범위가 칠해지지 않도록 각 마스크 primitive를 개별 경로로 렌더링한다.

## 검증

- 공유 타입과 게임 코어 TypeScript 검사
- 변경된 TS·TSX 파일 구문 검사
- 모든 객체 정답 영역의 경계·반지름·최소 간격 검사
- 제작자만 제출 가능하고 찾는 사람만 추측·힌트 사용이 가능한 코어 단위 테스트 갱신
- 제작 중 찾는 사람에게 편집 보드와 그림이 표시되지 않는 E2E 시나리오 갱신
- 제작자가 서로 다른 객체 3개를 선택한 뒤 제출하면 찾는 사람만 풀이 화면을 받는 E2E 시나리오 갱신
