# 변경 요약 — 문제 교환을 이미지 기반으로 (2026-07-20)

## 한 줄 요약

풀이 클라이언트에 정답 좌표가 노출되던 문제를 고치고, 그 과정에서 자동 보충·제작 마감·결과 공개 흐름을 함께 정리했다.

## 왜 필요했나

`IMPLEMENTATION_BACKLOG.md`의 P0 미완 항목 "정답 좌표가 풀이 클라이언트에 사전 노출되지 않는지 확인"을 점검하다가, **실제로 노출되고 있었음**을 확인했다.

`GameMatch.snapshot(viewerId)`는 `FINDING` 상태에서 상대의 `Difference[]`를 통째로 내보냈고, 각 항목의 `region: { x, y, radius }`가 곧 정답 위치다. 풀이 화면(`MvpApp.tsx`)이 이 배열로 그림을 합성했으므로, 개발자도구에서 소켓 메시지만 열어도 세 곳이 전부 보였다. `TEST_PLAN.md` 6절에 정면으로 걸리는 결함이다.

## 무엇을 바꿨나

**교환 방식** — 제작 명령을 풀이자에게 넘기지 않는다. 제작자 클라이언트가 그림을 합성해 이미지 한 장으로 만들고, 그 이미지만 서버를 거쳐 상대에게 전달된다. 정답 좌표와 제작 명령은 서버에 남는다.

**서버 부담** — 서버는 픽셀을 만지지 않는다. 이미지는 형식(webp/png)과 용량(3MB)만 검증한다. node-canvas 같은 의존성이 필요 없다.

**자동 보충** — 서버가 아니라 제작자 클라이언트가 마감 3초 전에 부족한 차이점을 채워 제출한다. 서버가 차이점을 주입해도 그에 맞는 이미지를 만들 수 없기 때문이다. (참고: 기존 서버측 `FALLBACK_DIFFERENCES`는 생성자 검증에만 쓰이고 실제로는 어디에서도 사용되지 않던 죽은 코드였다.)

**제작 마감 정책** — 마감까지 제출하지 않은 쪽은 기권, 양쪽 모두 미제출이면 승패 없이 취소.

**정답 공개** — 전체 정답은 `FINISHED` 이후에만 공개하며, 찾은 곳/놓친 곳을 구분해 보여준다.

## 파일별 변경

### packages/shared/src/index.ts
- `GameSnapshot.problem` 삭제 → `problemImage` · `foundMarks` · `revealedDifferences`로 분리
- `GuessResult.region` 추가 (맞힌 곳만 위치 반환, 오답이면 null)
- `game:submit` 이벤트에 `renderedImage` · `autoFilled` 추가
- `PlayerProgress.autoFilled` 추가
- `PROBLEM_IMAGE_LIMITS`, `GAME_CONFIG.autoSubmitLeadSeconds` 추가

### packages/game-core
- `snapshot()`: 풀이 중에는 이미지와 발견 위치만, 전체 정답은 종료 후에만 노출
- `validateProblemImage()` 신규 (형식·용량 검증)
- `submitDifferences()`: 렌더 이미지 인자 추가 및 검증
- `expire()`: 제작 마감 시 미제출자 기권 / 양쪽 미제출 취소
- 생성자에서 미사용 `fallbackDifferences` 인자 제거

### apps/server
- 제출 핸들러가 렌더 이미지를 코어로 전달
- 소켓 `maxHttpBufferSize`를 이미지 크기에 맞춤
- `MatchRegistry`의 죽은 `FALLBACK_DIFFERENCES` 제거

### UI
- `FreeformEditor`: 효과 렌더링을 재사용 함수로 분리, `renderProblemImage()`(합성), `buildAutoFilledDifferences()`(자동 보충)
- `use-game-client`: 제출 시그니처 변경, 발견 위치 추적(재접속 복원 포함)
- `MvpApp`: 이미지 기반 풀이 화면, SWAPPING 화면, 제출 대기·자동보충·렌더 오류 상태, 결과 화면 전체 정답 공개

## 테스트

기존 24개 → 30개 통과. 추가한 회귀 테스트:
- 풀이 중 스냅샷에 미발견 정답 좌표가 없음 (직렬화 payload 검사)
- 맞힌 곳만 위치 반환, 오답은 null
- 전체 정답은 종료 후에만 공개
- 잘못된/과대 이미지 제출 거절
- 자동 보충 플래그 표시
