# 2026-09-01 변경 요약 — 가로형 게임 WebView 대응

> 문서 상태: HISTORICAL

## 목적

앱인토스 게임 미니앱의 대표적인 가로형 저높이 viewport에서 원본과 변경본이 세로로 쌓여 플레이 영역이 화면 밖으로 밀리는 문제를 수정한다.

## 변경

- 높이 500px 이하 가로 화면에서 플레이 중 장식 헤더를 접고 상태바를 축소한다.
- 원본과 변경본을 844×390급 화면에서 좌우로 유지하고 남은 높이에 맞춰 정사각형 게임판을 축소한다.
- CSS 동적 viewport 단위와 Safe Area 환경 변수를 적용한다.
- 브라우저 핀치 줌을 비활성화하고 `viewport-fit=cover`를 적용한다. 게임 자체의 1~3배 확대 버튼은 유지한다.
- Chromium 2인 E2E의 한 플레이어를 844×390과 640×360으로 실행하고 두 게임판의 좌우 배치와 viewport 내부 표시를 검증한다.

## 검증

- `pnpm check`: 통과
- `pnpm e2e`: Chromium·Firefox·WebKit 9개 통과

앱인토스 SDK 설정 파일과 앱 식별 정보는 이 저장소에 아직 없으므로, 실제 샌드박스 앱의 네이티브 Safe Area와 배포 서버 연결은 별도 검증이 필요하다.
