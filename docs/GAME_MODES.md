# 게임 모드와 난이도

> 문서 상태: CURRENT
> 기준일: 2026-08-31
> 세부 수치와 승패는 `GAME_RULES.md`를 따른다.

모든 모드는 같은 원본·변경본 쌍에서 문제별 실제 차이를 모두 찾고, 정답 점수와 전체 덱 완주 시간 가산점을 합산하는 기본 규칙을 공유한다. 서버는 같은 모드와 난이도를 선택한 플레이어끼리만 매칭한다.

## 게임 모드

| 모드 | 코드 | 제한시간 | 추가 규칙 |
|---|---|---:|---|
| 기본전 | `STANDARD` | 180초 | 정답 점수와 완주 시간 가산점을 합산한다. |
| 속도전 | `SPRINT` | 60초 | 같은 점수 규칙을 짧게 진행한다. |
| 생존전 | `SURVIVAL` | 120초 | 누적 오답 3회에 먼저 도달하면 즉시 패배한다. |

## 난이도

난이도는 이미지 풀, 클릭 판정 범위와 오답 잠금을 함께 결정한다. `NORMAL`은 자산 등급 `MEDIUM`에 대응하며, 아직 평가되지 않은 `UNRATED` 문제는 모든 난이도의 공용 풀에 포함한다. 두 플레이어는 반드시 같은 난이도로 경기한다.

| 난이도 | 코드 | 이미지 풀 | 현재 수 | 정답 판정 반경 | 오답 잠금 |
|---|---|---|---:|---:|---:|
| 쉬움 | `EASY` | EASY + UNRATED | 11개 | 기준의 125% | 0.5초 |
| 보통 | `NORMAL` | MEDIUM + UNRATED | 6개 | 기준의 100% | 1초 |
| 어려움 | `HARD` | HARD + UNRATED | 3개 | 기준의 80% | 2초 |

현재 수량은 구현 현황이지 공개 출시 승인 수량이 아니다. 부족한 난이도 공개 여부와 최소 수량은 `REVIEW_REQUIRED.md`의 `REV-004`, `REV-005`에서 결정한다.

## 재미 피드백

정답을 연속으로 찾으면 콤보가 증가하고 2연속부터 화면에 표시한다. 오답이면 현재 콤보는 0으로 초기화되며 최고 콤보는 경기 복구 데이터에 유지된다. 콤보는 현재 승패 점수에는 영향을 주지 않는다.

## 공통 승패 기준

한 플레이어가 전체 덱을 먼저 완료하면 즉시 승리한다. 제한시간이 먼저 끝나면 다음 순서로 판정한다.

1. 총점이 높은 플레이어
2. 총점이 같으면 오답이 적은 플레이어
3. 오답도 같으면 무승부

생존전의 오답 3회 패배와 기권은 위 비교보다 먼저 적용된다. 모드, 난이도, 제한시간, 판정과 종료는 서버가 최종 결정한다.
