# UI 구현 기준

> 문서 상태: CURRENT
> 규칙은 `../../docs/GAME_RULES.md`, 화면 요구는 `../../docs/SCREEN_SPEC.md`를 따른다.

## 공통

- 활성 앱은 `MvpApp`이다.
- 게임 수치는 공유 `GAME_CONFIG`를 사용한다.
- 서버 스냅샷으로 시간·점수·승패를 확정한다.
- 두 플레이어에게 같은 원본·변경본 비교 권한을 제공한다.
- 상대가 찾은 정확한 위치와 미발견 정답은 종료 전에 표시하지 않는다.
- 문제 로드 완료 전에는 이미지를 가리고 서버 카운트다운을 따른다.

## 반응형과 입력

- 데스크톱은 좌우 비교, 모바일은 상하 또는 빠른 전환을 사용한다.
- 선택 좌표는 표시 크기가 아닌 정규화 좌표로 변환한다.
- 모바일 확대·이동 제스처와 정답 선택을 구분한다.
- 처리 중·입력 잠금·연결 끊김·종료 상태에서 중복 입력을 막는다.

## 접근성

- 모든 입력에 접근 가능한 이름과 명확한 포커스 표시를 제공한다.
- 정답·오답·잠금·경고를 색상만으로 전달하지 않는다.
- 아이콘 버튼에는 텍스트 이름 또는 `aria-label`을 제공한다.
- 애니메이션과 소리는 핵심 정보의 유일한 전달 수단으로 쓰지 않는다.

## 컴포넌트

- 한 영역의 주요 행동은 하나를 우선 강조한다.
- 오류 원인과 복구 행동을 가까이 표시한다.
- 실제로 제공하지 않는 기능을 비활성 시안에서 되살리지 않는다.
- 새 의존성을 추가하기 전에 활성 앱에 필요한지 확인한다.
